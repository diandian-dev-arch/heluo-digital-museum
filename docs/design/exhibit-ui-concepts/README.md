# 数字展厅 UI 色彩概念

本目录提供五套 1600x900 桌面高保真效果图。所有方案复用同一功能骨架和项目现有青铜鼎素材，只比较色彩、材质、留白与信息层级；现有 Vue、CSS、Three.js 和业务逻辑未修改。

| 序号 | 方案 | 主色板 | 设计气质 | 适用判断 |
|---|---|---|---|---|
| 01 | 月白青玉 | `#F4F2EC` `#173B34` `#A53A2B` `#94754A` | 明亮、克制、东方纸墨 | 与现有公开前台衔接最好，优先推荐 |
| 02 | 深墨鎏金 | `#08110E` `#0B1713` `#C69A4F` `#EEE6D7` | 沉浸、贵重、戏剧性 | 适合强调 3D 观赏，但需控制移动端暗部 |
| 03 | 石青博物馆 | `#E9EEF0` `#233B43` `#39766D` `#9B7448` | 理性、冷静、研究感 | 适合点云和数字研究叙事 |
| 04 | 朱砂编辑展陈 | `#F6F4EF` `#263F38` `#A93F32` `#8A6844` | 编辑式、清晰、展签感 | 信息可读性最强，推荐作为第二候选 |
| 05 | 河洛暮色 | `#1B2023` `#22282A` `#5D9A87` `#C19158` | 暮色、青玉、识别度高 | 品牌个性最强，适合限定展或夜间主题 |

## 共通设计约束

- 青铜鼎始终是视觉中心，信息板不能遮挡器物主体。
- 顶部导航、左侧 3D 工具、右侧信息、实体/点云、底部六段导览和五个视角全部保留。
- 主操作色每屏只承担一个主要动作，古铜金用于来源、编号和器物语义，不铺满界面。
- 半透明材质只用于悬浮工具和信息板，底部导览保持相对实色，避免玻璃层互相叠加。
- 后续落地动效采用可中断弹簧；普通展开默认无回弹，只有拖拽或甩动操作保留轻微动量。

## 推荐顺序

1. **01 月白青玉**：最不割裂，能直接继承当前“河洛纸墨”的月白、墨绿和朱砂体系。
2. **04 朱砂编辑展陈**：信息效率最高，适合展签和学术内容较多的展项。
3. **05 河洛暮色**：更有记忆点，可吸收其青玉高亮作为暗色模式。

建议最终采用 **01 的整体空间 + 04 的右侧信息栏 + 05 的青玉交互高亮**，而不是整套照搬单一方案。

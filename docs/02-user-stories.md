# 用户故事与页面流程

- 文档版本：v0.2
- 最后更新：2026-08-01
- 关联需求：`docs/01-requirements-traceability.md` 的 F-01 至 F-13。

## 1. 目标用户与产品定位

### 主目标用户

**18～30 岁的年轻文化探索者**，重点覆盖大学生和刚工作的年轻人。他们习惯使用互联网平台获取文化信息，愿意通过图文、故事和互动 3D 内容先在线感受博物馆，再决定是否预约线下参观或购买文创产品。

产品定位：

> 面向年轻文化探索者的河洛数字博物馆：用故事化内容、互动 3D 展项和线上线下联动，让传统文化更容易被看见、理解和分享。

### 兼容用户

普通游客、亲子家庭和对河洛文化感兴趣的访问者可以使用基础浏览、搜索与预约功能；但第一版的信息架构和交互优先服务主目标用户，不额外扩展儿童教育、学术研究或完整旅游票务功能。

## 2. 核心用户画像

### 小林：线上探索后决定到馆的大学生

| 维度 | 描述 |
|---|---|
| 身份 | 21 岁大学生，日常使用手机和社交平台获取信息。 |
| 动机 | 对传统文化感兴趣，但不想只阅读生硬、冗长的介绍。 |
| 行为 | 先在线浏览主题内容、文物故事和 3D 展项；感兴趣后再预约线下参观。 |
| 期待 | 页面清晰、内容有故事感、3D 可互动、预约简单、文创有设计感。 |
| 痛点 | 不知道从哪里开始了解；传统网站信息密集、缺少吸引力；预约入口难找。 |
| 成功标准 | 在几分钟内找到感兴趣的展品，在线感受到展览价值，并顺利完成预约。 |

### 小林的核心旅程

```text
发现博物馆/进入首页
→ 浏览本周主题与精选展品
→ 阅读文物故事或查看 3D 展项
→ 产生线下参观兴趣
→ 登录并提交预约
→ 到“我的预约”查看状态
→ 参观前后浏览或购买文创
```

## 3. 系统角色与访问范围

| 角色 | 典型身份 | 能力 |
|---|---|---|
| 游客 | 第一次访问的年轻文化探索者 | 浏览公开内容、搜索、查看 3D 展项和商品；不能提交预约或下单。 |
| 用户 | 已注册并计划到馆的年轻访客 | 具备游客能力；可提交/查看自己的预约、维护购物车、下单和查看个人订单。 |
| 管理员 | 博物馆内容或运营人员 | 管理内容、展项、预约、商品、订单、用户和基础统计。 |

## 5. 页面清单与核心流程

### 前台页面

| 页面 | 主要用户目标 | 主行动 |
|---|---|---|
| 首页 | 快速感受博物馆主题与精选内容 | 开始探索、进入 3D 展厅、预约参观。 |
| 文物/文章列表 | 按主题探索内容 | 分类筛选、关键词搜索。 |
| 文物/文章详情 | 理解一件展品或一个故事 | 继续探索、查看相关展项。 |
| 3D 展厅 | 在线互动感受展品 | 旋转、缩放、阅读展项说明。 |
| 预约页 | 安排线下参观 | 提交预约。 |
| 商城/商品详情 | 发现文化文创 | 加入购物车。 |
| 购物车/订单 | 完成购买 | 创建订单、模拟支付。 |
| 登录/个人中心 | 管理个人身份与记录 | 登录、查看预约和订单。 |

### 后台页面

```text
登录、仪表盘、文物管理、文章管理、3D 展项管理、预约管理、
商品管理、订单管理、用户管理。
```

### 关键流程与异常流程

#### 流程 A：线上探索到线下预约

```text
首页主题入口 → 内容详情/3D 展项 → 点击预约
→ 未登录：跳转登录，登录后回到预约页
→ 已登录：填写并校验表单（含联系人邮箱） → 创建待确认预约
→ 管理员确认/取消后向预约邮箱发送通知 → 我的预约查看状态
```

异常：模型加载失败时显示说明和重试入口；预约日期、人数、邮箱或其他必填项无效时显示对应错误；预约提交失败时保留已填写内容并提示重试；邮件投递失败不得改变预约状态。

#### 流程 B：商城下单

```text
商品列表 → 商品详情 → 加入购物车 → 创建订单（确认最终金额与通知邮箱）
→ 模拟支付 → 订单变为已支付 → 向通知邮箱发送状态邮件 → 我的订单查看记录
```

异常：商品下架、库存不足、数量超过上限、价格变化、重复支付或网络请求失败时，系统不得生成重复扣库存或重复支付结果，并给出明确提示；支付邮件发送失败不得改变支付结果。

#### 流程 C：管理员发布内容

```text
管理员登录 → 新建/编辑文物或文章 → 保存草稿或发布
→ 前台列表与详情展示已发布内容 → 后台可撤回、更新或软删除
→ 已删除内容进入回收站；恢复后为已撤回，需再次发布
```

异常：非管理员访问后台时返回无权限；必填内容缺失时不允许发布；发布失败时保留编辑内容并显示错误原因；已删除内容不在前台展示，恢复后仍需管理员重新发布。

## 6. 页面设计原则

- 首页优先展示主题、故事和探索入口，不做信息堆叠的传统公告页。
- 内容先提供吸引人的摘要、亮点和时代背景，再提供完整资料。
- 3D 是帮助理解展品的互动方式，不以复杂特效替代内容。
- 预约入口在首页、内容详情和 3D 展厅中保持可发现。
- 商城商品必须提供文化故事或设计说明，不只是价格和图片。
- 所有核心流程在手机端同样可完成；表单、空状态、加载和失败状态必须清晰。

## 7. 后续待细化

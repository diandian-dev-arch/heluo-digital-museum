# ADR-003：内容与商品采用软删除

- 状态：已接受
- 日期：2026-08-01
- 关联需求：F-04、F-11、N-01

## 背景

博物馆内容、展项和商品需要支持管理员的删除操作，但直接物理删除会导致误操作无法恢复，也可能破坏历史订单、操作记录和数据统计的一致性。

## 决策

文物、文章、3D 展项和商品的删除默认采用软删除：

```text
deleted_at：为空表示未删除；存在时间表示已删除
deleted_by：执行删除的管理员 ID
```

- 内容的发布状态独立保存为 `DRAFT`、`PUBLISHED`、`WITHDRAWN`。
- 已删除内容不在前台结果中展示，后台可按“已删除/回收站”筛选。
- 恢复内容后状态为 `WITHDRAWN`，必须由管理员再次发布后才能前台可见。
- 已产生订单的商品优先下架；历史订单保留商品名称、单价、数量等快照。
- 第一版不为普通管理员提供永久物理删除。

## 后果

- 数据表需要增加软删除字段和相应查询过滤规则。
- 管理后台需要支持回收站、恢复和操作日志。
- 前台、搜索和统计查询必须排除软删除记录。
- 后续若设计数据清理机制，必须先明确备份、保留期限和权限，并新增 ADR。

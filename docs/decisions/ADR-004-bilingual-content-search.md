# ADR-004：双语内容字段与公开关键词搜索

- 日期：2026-09-17
- 状态：已接受，用户已授权按双语搜索方案实施；生产发布另行授权。

## 背景

Explore 英文标题和摘要此前仅在前端映射，后端只搜索数据库中文字段，导致英文页面可见的名称无法检索。

## 决策

文物和文章保留 title/summary，新增可空 title_en/summary_en。公开搜索与列表 keyword 同时匹配四字段，忽略英文大小写、按字面处理 SQL 通配字符。后台维护译文，前端列表、搜索和详情标题/摘要共享逐字段语言回退逻辑。

历史内容通过 Flyway 增量迁移补齐，新建演示数据在首次初始化时带译文；初始化不能重新填入管理员主动清除的译文。迁移保持历史文本自包含，不依赖会继续变化的初始化常量。

## 取舍

当前只需中英两种语言，显式双语列比通用翻译表简单。不引入搜索引擎、AI 翻译或向量数据库；仍为字符串包含匹配，不支持同义词和语义理解。缺译回退中文，新增内容需由管理员补译。未来语言数量或数据规模明显增长时重新评估结构与索引。

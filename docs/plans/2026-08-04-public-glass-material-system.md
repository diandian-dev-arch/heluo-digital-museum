# 全站毛玻璃材质系统统一计划

## 目标

- 以首页导航的灰绿月白玻璃为浅色基准，统一所有公共前台浅色玻璃看板。
- 以首页参观路线的墨玉玻璃为深色基准，统一图片信息条、登录卡和展项信息卡。
- 将内容管理与运营管理纳入同一材质契约，避免后台继续维护独立的透明背景、边框和阴影。
- 收口背景色、边框、高光、模糊、饱和度、阴影与圆角，保留不同页面的信息层级。
- 为减少透明度和高对比度偏好提供统一实色降级。

## 关联需求

- F-01 公开内容浏览
- F-03 文物与文章详情
- F-05 3D 数字展项
- F-06 预约参观
- F-08 用户身份与个人中心
- F-09 文创商城
- F-12 中英文切换
- N-03 响应式与视觉可用性
- N-06 可维护性与一致性

## 实施步骤

1. 审计公共前台所有 `backdrop-filter`、半透明背景、边框和阴影参数。
2. 建立月白青玉、深墨玉与紧凑玻璃三个共享材质层级。
3. 通过 `data-glass="light|dark|compact"` 映射浅色看板、深色信息层、移动浮层和后台工作面，不改变业务结构。
4. 统一减少透明度和高对比度模式下的实色降级。
5. 增加材质契约测试，阻止重复令牌、非法层级和页面级材质覆盖回归。
6. 运行类型检查、单元测试、生产构建，并在桌面和手机尺寸逐页回归。

## 验收标准

- 同级浅色玻璃使用相同背景、边框、高光、模糊、饱和度和阴影参数。
- 同级深色玻璃使用相同墨玉色相和透明度，文字对比度清楚。
- 首页、馆藏、展厅、预约、商城、登录和个人中心无孤立的灰白或偏色玻璃卡。
- 内容管理和运营管理的侧栏、统计、表单、记录及控件使用同一三层契约。
- `1433x746` 与 `390x844` 下无横向溢出、文字截断或控件遮挡。
- 减少透明度和高对比度模式不依赖模糊仍可清晰阅读。

## 风险

- 页面背景明暗不同，不能把深色信息层机械改为浅色；统一的是材质规则和色彩体系，而不是取消层级。
- 全站覆盖选择器较多，必须以浏览器逐页检查防止旧规则优先级反压新令牌。

## 验证结果

- 实现：`main.css` 末端建立唯一 canonical 令牌层；`light` 使用 `95.5% .006 158 / .72` 与 `24px / 126%` 滤镜，`dark` 使用 `30% .047 170 / .88`，`compact` 使用 `14px / 118%` 滤镜；大表面/紧凑控件圆角分别为 `8px`/`6px`。
- 契约：所有登记表面使用合法 `data-glass` 值；输入、Element Plus 浮层、次级按钮和后台标签复用紧凑层；主操作与危险操作保留既有实色语义。
- 降级：减少透明度、高对比度和强制颜色模式均有不依赖模糊的实色/系统色路径；禁用交互统一不可用光标和透明度。
- 自动化：`pnpm test` 通过，15 个测试文件共 53 项；其中材质契约 5 项覆盖令牌唯一性、语义规则无临时颜色、旧 feature 令牌禁用、遗留覆盖拦截和登记表面完整性。`pnpm typecheck`、`pnpm build`、`git diff --check` 全部通过。
- 响应式：公共 10 路由完成 `1433x746` 与 `390x844`；7 个核心路由完成 `320/375/414/768/1440/1708px` 共 42 组布局检查，均满足 `scrollWidth === clientWidth`。这属于浏览器尺寸模拟，不等同真实手机验收。
- 材质一致性：首页、馆藏、3D、预约、商城、登录、个人中心、后台内容与后台运营同层级计算值无漂移；最终 Docker 生产页首页与 3D 页的 `light/dark/compact` 均各只有 1 个计算值变体，Bottom Sheet 与首页导航的背景、边框、阴影、滤镜和圆角一致。
- 3D：桌面 Canvas 区域 RGB 标准差为 `81.94/72.55/75.35`，手机为 `66.15/68.58/73.01`，确认不是空白或纯色画布；手机截图中鼎、底座、工具和 Dock 完整出现。
- 交互：馆藏搜索、商城分类与购物车增减、实体/点云双向切换、预约填写、管理员登录、后台商品标签和商品编辑入口均完成回归，测试数据已恢复或未提交。
- 部署：Docker frontend/backend 镜像重建成功，MySQL 与 Mailpit healthy；`http://localhost:8088/` 返回 `200`，`/api/v1/health` 返回 `UP`，最终首页与 3D 页控制台无 warning/error。
- Hallmark：六轴自评为 `P5 H5 E5 S5 R5 V5`；58 项 slop test 以本轮材质契约为审计对象全部通过。旧 `main.css` 仍包含历史页面样式，本结论不表示整个旧样式文件已完成全量令牌化。

## 2026-08-04 Apple 材质透明度精修

- 目标：解决现有青绿色偏实、偏艳和显廉价的问题，在既有三层契约内改为更通透的低彩度墨绿材质。
- 影响：仅调整 canonical 玻璃令牌、材质门禁测试与设计契约；不修改页面结构、路由、API、权限、业务数据或 Three.js 逻辑。
- 实施：light、dark、compact 的透明度分别调整为 `.48`、`.58`、`.52`；深墨色彩度降至 `.028`，大/小表面滤镜统一为 `30px / 112%` 与 `18px / 110%`，阴影与边框改为更中性的低透明参数。
- 无障碍：减少透明度模式使用更高不透明度的 `.82/.78/.84` 无模糊材质，高对比度模式继续使用低彩度实色；两者不再共用一块生硬纯绿方块。
- 验收：同层计算值保持唯一；正常模式背景环境清晰可感知；降级模式保持文字可读且不呈现高彩度实绿；桌面与手机关键路由无溢出或控制台错误。
- 验证结果：待本轮自动化、生产构建、Docker 与浏览器回归后补充。

# 后台管理参考图重构实施计划

## 目标

在不改变后台 API、权限和业务动作的前提下，参照用户提供的两张效果图，重建内容管理与运营管理的前端视觉和信息架构：纸面工作台、印章式品牌、紧凑统计、内容表格和运营侧栏。

## 关联需求

- F-04：管理员可新增、编辑、发布、撤回、软删除和恢复内容。
- F-07：管理员可查看和更新预约状态。
- F-11：管理员可管理商品和订单。
- F-13：管理员可查看基础运营统计。
- N-03/N-06：响应式、可维护和可验证的前端界面。

## 影响范围

- frontend/src/components/AdminShell.vue：重建后台壳层、品牌区、导航图标和页面标题区。
- frontend/src/views/AdminContentView.vue：增加内容封面、状态/分类/日期/操作列和稳定的表格结构。
- frontend/src/views/AdminOperationsView.vue：补充运营统计、趋势侧栏和运营工作区布局；保留原有模块动作。
- frontend/src/assets/main.css：新增后台参考图视觉令牌、纸墨背景、表格、趋势卡和移动端规则。
- PROJECT_STATUS.md、docs/01-requirements-traceability.md：记录实施结果和验证证据。

## 设计决策

- 内容管理使用浅色宣纸背景、细线分栏、朱砂当前态和衬线大标题，对齐第一张参考图。
- 运营管理复用同一壳层，在统计与趋势侧栏中提高朱砂色数据优先级，对齐第二张参考图。
- 桌面端使用侧栏 + 工作区；移动端将侧栏折叠为顶部导航，内容记录转为可操作记录卡，避免横向滚动。
- 不引入新依赖；封面缺失时使用现有本地展项素材作为可理解的降级图。

## 验收标准

1. /admin 和 /admin/operations 保持管理员权限校验和原有 API 请求路径。
2. 内容页显示统计、文物/文章切换、草稿表单、封面列表和编辑/发布/撤回/删除/恢复操作。
3. 运营页显示统计、七个运营模块、创建表单、记录操作和运营趋势侧栏。
4. 1440px 和 390px 下无关键横向溢出，移动端表单和记录操作可继续完成。
5. 类型检查、单元测试和生产构建通过；浏览器抽查无控制台错误。

## 验证结果

- pnpm typecheck：通过。
- pnpm test：3 个测试文件、7 个测试通过。
- pnpm build：通过；保留既有大分包提示。
- Playwright Chromium 模拟数据浏览器回归：1440×900 内容页、运营页和 390×844 内容页；页面宽度与 viewport 一致，图片加载失败数为 0，控制台错误为 0。
- Docker 实际验收：执行 docker compose -f deploy/compose.yaml up -d --build frontend；deploy-frontend-1 重新创建并运行，访问 http://127.0.0.1:8088/login 登录管理员后进入 /admin，页面标题和新版纸墨后台结构已确认；MySQL healthy，backend/frontend 均为 Up。

## 未覆盖与风险

- 本轮使用浏览器模拟数据验证布局，未替代真实后端管理员登录和真实设备触摸验收。
- 运营趋势图为基础统计的轻量视觉摘要，不新增统计 API；后续若需要按日趋势应单独扩展后端契约。

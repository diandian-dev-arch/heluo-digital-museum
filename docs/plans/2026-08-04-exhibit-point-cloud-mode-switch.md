# 数字展项实体与点云双向切换修复计划

## 目标

修复进入点云解构后返回实体模型的入口不明确问题，并提升实体/点云模式切换在导览 Dock 中的视觉优先级。

## 关联需求

- F-05：数字展项实体与点云交互
- N-03/N-06：响应式、可发现性和工程验证

## 影响范围

- `frontend/src/views/ExhibitDetailView.vue`
- `frontend/src/assets/main.css`
- 数字展项相关前端测试与项目状态文档

## 实施步骤

1. 将点云导览步骤从单向进入改为实体/点云双向切换。
2. 强化 Dock 模式分段控件的尺寸、标签、状态说明和对比度。
3. 保持桌面和手机模式控件始终可见，并提供清晰的按压、焦点和禁用状态。
4. 运行类型检查、测试、生产构建、Docker 重建及桌面/手机浏览器回归。

## 验收标准

- 点击“点云解构”可进入点云，再次点击或点击“实体模型”可返回 PBR 实体。
- 当前模式无需阅读说明即可辨识，实体与点云入口均保持可见。
- `1433x746` 与 `390x844` 无横向溢出或 Dock 遮挡。
- 控制台无新增错误，类型检查、测试和生产构建通过。

## 风险

- Dock 高度会影响鼎的首屏完整性，因此优先重排现有区域，不扩大整体遮挡高度。
- 点云不可用的回退设备必须保持禁用状态和实体展示。

## 验证结果

- `corepack pnpm typecheck`：通过。
- `corepack pnpm test -- --run`：11 个测试文件、39 项测试全部通过；新增用例覆盖导览第 5 步从实体进入点云、再返回实体的完整状态变化。
- `corepack pnpm build`：通过；仅保留既有 Three.js 分包超过 500 kB 的构建提示。
- Docker：前端镜像构建成功，manifest 为 `sha256:4d3ecfc3a6ca8c6eca6f5a64b02866834d8fd82dc117e957552b783db3094d5f`；`deploy-frontend-1` 已重建并运行，`http://localhost:8088/` 返回 `200 OK`。
- 桌面 `1433x746`：导览按钮和 Dock 均完成实体 -> 点云 -> 实体双向切换；点云态明确显示“返回实体模型”“返回实体 / 点云已开启”；页面无横向溢出，控制台无警告或错误。

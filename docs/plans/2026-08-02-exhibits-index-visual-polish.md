# 数字展厅列表页视觉优化

## 目标

修复 `/exhibits` 首屏在桌面端出现大块空白、标题贴顶以及展项信息层级不清的问题，使页面更接近“河洛纸墨”的编辑式数字展厅：标题先建立阅读节奏，展项卡片用图像与说明并置，移动端自然堆叠。

## 关联需求

- F-05：游客可进入 3D 展厅查看已发布展项。
- N-03：桌面与手机端无关键横向溢出，并提供清晰的加载/内容层级。

## 实施范围

- `frontend/src/assets/main.css`
  - 为展厅索引补充编号栏、标题区、交互说明和统计信息布局。
  - 将展项卡片改为明确的“左图右文”双栏，取消由 CSS Grid 自动放置造成的空白象限。
  - 增加 hover、焦点可见的编辑式边框、阴影和 CTA 反馈。
  - 在 900px 与 640px 断点下切换为紧凑双栏和移动端上下堆叠。
  - 为移动底部导航补齐显隐、尺寸和 SVG 图标盒模型，避免桌面端 SVG 撑高页面。

## 验收标准

1. 1440px 桌面端标题不被导航遮挡，展项图片与说明在同一张卡片内呈现。
2. 390px 移动端无横向滚动，卡片上下堆叠，底部导航固定且图标尺寸正常。
3. 交互入口仍指向既有展项详情路由，不改变 API 与业务数据结构。

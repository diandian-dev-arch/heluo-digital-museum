# 原创河洛青铜鼎 v5 建模与 PBR 材质优化计划

- 日期：2026-08-01
- 状态：已实施，待项目组视觉验收与真实手机复验
- 关联需求：A-02（自主创作 3D 资产）、F-05（3D 展项展示）、N-03（移动端可用性）、N-06（可维护性）
- 当前线上基线：`heluo-bronze-ding-v4.glb`；本计划不覆盖该版本。

## 1. 目标与问题定义

将当前偏“塑料玩具”的青铜鼎升级为可在 Three.js 中稳定呈现的原创数字展项。核心问题是器形由简单部件拼装、正面存在贴片式纹样、材质颜色和粗糙度过于均匀，以及 Blender 预览与网页 GLB 材质表现不一致。

v5 的视觉目标为：深褐黑的厚重铸造青铜、克制的凹槽铜锈、连续河洛抽象浮雕、结构合理的双耳三足；它是项目自主创作的概念礼器，不复原或复制任何真实馆藏。

## 2. 实施边界

### 包含

- 新增独立的 v5 `.blend`、可重复生成脚本、GLB、封面渲染和资产说明。
- 按已生成的主视觉与四视图参考重做器身、口沿、双耳、三足和连续浮雕。
- 为网页导出 glTF 兼容的 PBR 材质；必要时烘焙贴图。
- 在现有 Three.js 点云展厅中替换试运行，并完成桌面与移动端验收。

### 不包含

- 不改变后端接口、展项数据结构或点云交互逻辑。
- 不覆盖、删除或改写 v1 至 v4 资产。
- 不引入第三方文物模型、商业扫描数据或未经登记的纹样贴图。

## 3. 设计与建模标准

### 器形

- 椭圆形厚实双层口沿；器腹上部收束、腹部圆润但不臃肿、底部自然内收。
- 两只方圆形立耳具有厚度、轻微锥度、耳根过渡和可靠附着关系。
- 三足按前一后二的稳定结构布置，足根有束腰/领圈，足部为略带棱面的锥台而非简单方块。
- 展示比例基准：口沿总宽 : 器腹高 : 足高约为 `1 : 0.62 : 0.75`；仅作为首轮 blockout 基准，须用四视图确认后微调。

### 纹样

- 以抽象河洛水系流线、几何兽面节奏为灵感，形成绕器腹连续的浅浮雕带。
- 纹样必须贴合曲面，禁止使用单独的大矩形正面贴板。
- 耳部、足部纹样较简；器腹是视觉重心，避免密集堆砌。

### PBR 材质

- 主色：深褐黑青铜；不是整件金色或整件翠绿色。
- 凸起边缘保留暖铜磨损高光，凹槽、耳根和足根出现少量低饱和蓝绿铜锈。
- 使用颜色变化、微法线、粗糙度变化和 AO 建立铸造颗粒、磨损与缝隙深度。
- 网页最终使用 `baseColor`、`normal`、`roughness`、`metallic`、`occlusion` 五类 glTF 兼容信息；不依赖 Blender 专有程序节点或单独的场景色彩滤镜。

## 4. 分阶段实施步骤

### 阶段 0：确认与建模文件准备

1. 由项目组确认当前主视觉和四视图作为 v5 的设计基准。
2. 将确认后的设计参考复制到 `assets/models/bronze-ding/reference/`，登记 AI 生成来源、用途和确认日期；不把临时生成目录作为项目依赖。
3. 从 v4 另存为 `source/heluo-bronze-ding-v5.blend`，并复制/改写生成脚本为 `source/create_heluo_bronze_ding_v5.py`。
4. 保留 v4 的相机、灯光与导出预设，仅将模型本体放入新的 `MODEL_HeluoBronzeDing_V5` Collection。

**验收**：v4 文件不被改写；v5 文件、脚本、参考图和来源记录齐全。

### 阶段 1：低模结构与比例（Blockout）

1. 使用器身曲面或旋转剖面建立连续、可见内壁的器腹，而非仅缩放球体。
2. 单独建立双层口沿、双耳、三足和足根领圈；所有部件保持真实接触关系。
3. 依据正面、侧面、俯视参考校正轴对称、口沿椭圆度、三足落点和器物重心。
4. 应用缩放、统一物体原点、命名对象；完成前不加入复杂纹样。

**验收**：关闭所有材质和纹样后，轮廓仍清楚表现为端正、稳定、厚重的三足鼎。

### 阶段 2：中高模细节与连续纹样

1. 以曲线加 Shrinkwrap 或贴附网格方式绘制连续浮雕，随后转为适合导出的网格。
2. 在器腹制作一条主浮雕带、一条简化肩部带和少量圆形乳钉；控制凹凸深度。
3. 使用 Bevel、Weighted Normal 和 Auto Smooth 保留金属倒角，不以高密度随机噪声代替结构细节。
4. 在耳部、足部只放少量呼应纹样，清理穿模、漂浮、重叠面和背面未闭合区域。

**验收**：无矩形贴板；纹样从正面自然延续至侧面与背面；正常距离下能读到主纹样，近距离无明显穿模。

### 阶段 3：UV、烘焙与 PBR 材质

1. 展开 UV，统一贴图密度；器腹、双耳、三足和独立纹样不产生重叠或拉伸。
2. 创建高模细节后，烘焙 `normal`、`ambient occlusion` 和曲率遮罩。
3. 制作深褐黑青铜基础色，添加低强度铸造颗粒和非均匀粗糙度。
4. 将铜锈限制在 AO/凹槽遮罩区域；将暖铜高光限制在曲率/边缘遮罩区域。
5. 将最终效果烘焙为 glTF 兼容贴图或标准 Principled PBR 参数，并在新建干净 Blender 场景中复查。

**验收**：材质在强光、弱光、正面和侧面下都有金属层次；不呈现塑料般的均匀高光，不出现大面积荧光绿。

### 阶段 4：导出、网页接入与验证

1. 导出 `export/heluo-bronze-ding-v5.glb`；仅包含模型所需网格、材质、UV 和贴图，移除相机、地面和无用对象。
2. 新渲染封面图 `preview/heluo-bronze-ding-v5-cover.png`，保存四视图和材质球证据图。
3. 使用 Blender 重导入 GLB，并在现有 `ThreeExhibitViewer.vue` 中临时加载 v5 做实体/点云模式验证。
4. 检查初次加载、旋转、缩放、重置、点云采样、移动端性能及 WebGL 降级封面。
5. 验收后再将前端正式资源引用从 v4 切换至 v5，同步资产 README、需求追踪表和项目状态。

**验收**：v5 GLB 在浏览器中无材质丢失、无控制台错误；实体与点云模式都正常；移动端仍可交互或按既有策略降级。

## 6. 性能预算与风险控制

- 首选导出目标：GLB 不超过 8 MB；若需 4K 烘焙贴图，先测试 2K 贴图是否足够。
- 点云模式的 MeshSurfaceSampler 需要足够的三角面，但不能无上限细分；优先把微小颗粒放进法线贴图，而不是几何体。
- 纹样使用实例、镜像或烘焙，避免大量独立微网格。
- 每阶段建立一个版本快照；任一阶段不满意时只回退 v5，v4 持续可用。
- Blender 渲染效果不是网页保证：必须以 GLB 在 Three.js 中的实际灯光、色调映射和移动端表现作为最终验收依据。

## 目标

统一首页、数字展项、预约和商城中已存在的玻璃界面颜色与层级；修复商城进入单一分类后缺少返回“全部商品”入口的问题。

## 实施步骤

1. 新增烟青玉深色玻璃、月白浅色玻璃、古铜强调、边框、阴影和模糊语义令牌。

3. 为商城分类增加“全部文创”，保留三类筛选和 `aria-pressed` 当前态。
4. 增加商城默认三商品、单类筛选和返回全部商品的单元测试。

## 购物袋商品封面修复

### 问题与根因

- 商品列表会在 API `coverImageUrl` 为空时按稳定 `slug` 回退项目内正式 WebP，购物袋却直接渲染接口原值。
- 当前生产商品数据的封面字段为空，因此三个购物袋 `<img>` 都收到空 `src`，而商品舞台因已有局部回退显示正常。

### 实施

- 新增 `frontend/src/lib/productPresentation.ts`，统一按 `slug` 解析三件首发商品的正式封面和摘要，并为只含中文商品名的旧购物袋条目保留兼容映射。
- 商品舞台和购物袋共用同一解析器；后台管理员提供的非空封面仍优先，不会被回退资源覆盖。
- 购物袋图片加载失败时再次切换到已登记的正式 WebP，避免旧自定义 URL 失效后出现破图。

### 验证结果

- `corepack pnpm typecheck`：通过。
- `corepack pnpm test`：14 个测试文件、48 项全部通过，覆盖空封面、旧商品名映射和自定义封面优先级。
- `corepack pnpm build`：通过；无新依赖。
- 登录态 `1708x746` 购物袋实页审计：笔记本、丝巾和茶杯三张图均为 `complete=true`、`naturalWidth=960`，横向溢出 `0`，控制台 warning/error `0`。
- 16 组首页/商城页面映射门禁通过，`noClippedControls=true`；移动购物袋数量角标收回按钮边界内，不再造成控件宽度溢出。
- 生产前端更新为本地镜像 `sha256:e865ee3bb66f8a5bb191929a99ea48491e1d8743167cf77f86ab5a85b8114e9b`；容器与标签镜像一致，截图和结构化结果位于本地忽略目录 `artifacts/cart-image-fix/`。

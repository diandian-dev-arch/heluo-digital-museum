# 浏览器标注视觉精修

- 日期：2026-08-02
- 状态：已完成（真实设备待补验）
- 关联需求：F-04、F-06、F-07、F-11、F-13、N-03、N-06

## 目标

根据浏览器四处标注，优化预约路线示意、后台同类型下拉面板、运营数据数字字体和馆藏延伸阅读卡片，同时保持现有路由、接口、权限与表单数据结构不变。

## 影响范围

- `frontend/src/views/AppointmentView.vue`：重画三站式参观路线。
- `frontend/src/views/AdminContentView.vue`、`AdminOperationsView.vue`：统一后台选择控件及其浮层。
- `frontend/src/views/ExploreView.vue`：为延伸阅读建立主次分明的编辑式卡片结构。
- `frontend/src/assets/main.css`、`interaction.css`：补充路线、数字、选择器和卡片样式。

## 实施步骤

1. 将预约路线改为连续路径、三站节点和简洁站名，减少方框堆叠。
2. 复用现有 Element Plus，将后台原生选择框统一为可访问的浮层选择器。
3. 将运营指标统一为无衬线等宽数字，修正金额字形与字距。
4. 将延伸阅读改为一张主卡配两张横向卡，强化图片、标题、摘要和入口层级。
5. 运行类型检查、单元测试、生产构建，并在四个标注页面进行桌面与移动浏览器复验。

## 验收标准

- 路线图三站信息清晰、无拥挤或文字越界。
- 后台所有选择控件具有一致的触发器、展开浮层、选中态、焦点态和移动端宽度。
- 概览数字不再使用 Georgia，金额在窄卡片中不溢出。
- 阅读卡片具有明确主次，桌面和移动端无横向溢出，整卡可点击且焦点清晰。
- 相关检查通过；未通过项如实记录。

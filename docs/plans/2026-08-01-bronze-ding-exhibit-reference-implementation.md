# 青铜鼎 v5.3 参考图展项页实施计划

## 目标

基于参考图、`docs/prompts/河洛青铜鼎-v5.3-建模与点云展厅提示词.txt` 和现有 `heluo-bronze-ding-v5.3.glb`，把当前 3D 展项详情页收敛为深墨绿/古铜金的沉浸式数字展厅页面。保留现有模型旋转、缩放、预设视角、实体/点云切换、错误降级、移动端 Bottom Sheet 和 v5.2 回退能力。

## 关联需求

- 3D 展项展示：真实 GLB 加载、旋转、缩放、预设视角和加载失败降级。
- 点云展厅：实体/点云切换、按当前项目质量档采样、低帧率降级。
- 内容真实性：当前 1962.281 模型信息不得继续显示未经来源支持的商代年代或洛阳位置。
- 响应式与可访问性：桌面参考图布局、移动端可用、键盘焦点和减少动态效果。

## 影响范围

- `frontend/src/views/ExhibitDetailView.vue`：校正展项标题、来源/材质信息、导览和模型来源文案。
- `frontend/src/assets/main.css`：将展项详情页对齐参考图的全屏深色展厅、顶部导航、信息面板和底部导览结构；保留移动端规则。
- `frontend/src/components/ThreeExhibitViewer.vue`：仅在视觉验证证明必要时微调 v5.3 模型照明，不改变模型采样算法或质量分档。
- `docs/01-requirements-traceability.md`：记录参考图展项页验收状态（如本次完成了可追踪需求变更）。
- `PROJECT_STATUS.md`：记录本次页面实现和验证结果。

## 实施步骤

1. 读取现有展项页、项目设计系统、v5.3 资产和后端展项响应，确认不覆盖用户已有未提交改动。
2. 将不准确的“商代晚期”“洛阳盆地中部”等静态事实改为来源台账可支持的 `Cleveland Museum of Art · 1962.281`、材质重制和候选版本信息。
3. 调整沉浸式展项页面的桌面高度分配，使参考图视口内形成“顶部导航 + 3D 场景 + 底部导览”；描述正文保留在导览之后，不阻断主画面。
4. 统一深墨绿、古铜金和米白色层级，避免白色导航/底部导览覆盖参考图的展厅氛围。
5. 保留现有 API、路由、实体/点云控制器和 v5.3 GLB 路径；不新增依赖。
6. 在 1440×900、1672×941、1280×800、768×1024、390×844 进行浏览器回归，检查模型、面板、导览、滚动和移动端信息 Sheet。

## 验收标准

- 桌面页面顶部导航、左侧竖向展陈标识、左侧控制条、中心真实 v5.3 模型、右侧信息面板、底部导览均可见且无重叠。
- 页面主画面使用深墨绿/古铜金；面板和按钮的 active/focus/disabled 状态清晰。
- 信息面板不再显示未经来源支持的文物年代或地理位置；准确显示 1962.281 来源和 v5.3 候选状态。
- 实体/点云切换、旋转、放大、缩小、重置、五个视角按钮和关联入口仍可用。
- v5.3 GLB HTTP 请求返回 200；加载失败仍能显示封面和重试按钮。
- `pnpm typecheck`、`pnpm test`、`pnpm build` 通过；浏览器控制台无新增错误。
- 现有 v5.2 回退资源和未涉及页面不被删除或改写。

## 风险

- 真实手机触摸性能和辅助功能媒体特性仍需要实体设备补充验证。
- 参考图中的年代文案与当前 1962.281 来源不一致，本次以来源真实性优先，使用来源/材质/版本信息替代。
- 当前工作树已有大量未提交改动，本次只审查本任务相关文件，不提交 Git。

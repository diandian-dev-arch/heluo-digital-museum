# 原创青铜鼎模型精修 v2

- 日期：2026-08-01
- 状态：已完成 v3 精修，待用户确认
- 关联需求：A-02、F-05

## 反馈与目标

用户反馈 v1 模型与已确认的效果图差距较大：器腹过于圆钝、纹样仅为小凸点、整体缺乏青铜鼎的精致感。本次保留 v1，不覆盖原文件；新增 v2，重点提升器形比例、纹样层次、三足造型、双耳与渲染展示。

## 设计调整

1. 将器腹调整为更收束的圆鼎比例，突出厚重口沿和双层纹样带。
2. 使用成组的河洛流线/兽面抽象浮雕替换 v1 的单一凸点。
3. 使用三组方锥形腿和腿部装饰，形成更接近礼器的结构。
4. 调整青铜绿锈、暗金点缀、深色展台、正面博物馆布光和相机视角。
5. 输出独立 `v2` 的 `.blend`、`.glb`、封面和验证记录。

## v4 Web 材质修订

- 用户指出 v3 的亮绿色不符合预期。已将当前推荐版本改为 `v4`：以深棕黑的古朴青铜为主体、暗金为局部点缀；网站深墨绿仅作为展厅背景，不再作为器物主色。
- v3 使用 Blender 程序噪声节点，这类节点不会随 GLB 作为贴图导出，因此网页端不能保证复现 Blender 绿锈效果。v4 改用 glTF 兼容的标准 PBR `baseColorFactor`、金属度和粗糙度。
- 已解析 v4 GLB：5 种材质均含明确基础色，且没有外部图片依赖。仍需在 Three.js 场景中配置灯光和环境，才能复现合适的金属高光。

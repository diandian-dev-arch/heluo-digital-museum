# 数字展厅 UI 优化效果图计划（第二轮）

## 目标

针对当前三足青铜鼎数字展厅的界面层级、控件组织和操作效率，生成三套可映射到现有 Vue 组件的高保真 UI 效果图。保持青铜鼎、3D 场景、灯光和展台不变，不再把重点放在美术氛围变化。

## 关联需求

- F-05：3D 展项加载、旋转、缩放、实体/点云切换和预设视角。
- N-03：界面清晰、无明显遮挡，核心操作易发现。
- N-06：状态与交互反馈可理解，组件结构可维护。

## 当前 UI 问题

1. 右侧信息卡边框和高度过重，抢夺青铜鼎主体注意力。
2. 左侧四项工具垂直堆叠过高，按钮之间没有主次或当前状态。
3. 实体/点云、画质状态和来源信息分散，用户需要跨区域读取。
4. 底部导览、视角缩略图和模型来源被切成三块，视觉节奏零碎。
5. 当前视角只依赖细边框反馈，识别度不足。
6. 卡片、按钮、分隔线大量采用同等级描边，界面显得拥挤。

## 三套 UI 架构

1. 均衡侧栏式：保留桌面右侧信息栏，重整信息层级和底部控制坞。
2. 沉浸浮动式：信息默认收起为摘要，核心工具围绕画布形成低干扰浮动控制。
3. 导览任务式：以六段导览为主线，当前步骤驱动说明和视角切换。

## 不变项

- 现有青铜鼎、展台、深色场景和灯光。
- 顶部品牌导航、返回展厅、四项视角工具、实体/点云、六段导览、五个视角、关联文物和预约入口。
- `三足青铜鼎 · 1962.281` 与 `Cleveland Museum of Art · 1962.281`。
- 不新增测量、标注、切面、对比、图层等第一版范围外功能。

## 验收标准

- 三张图只改变 UI，不替换青铜鼎或重做展厅美术场景。
- 每张均体现清楚的操作主次、选中状态、信息层级和底部控制关系。
- 三套方案可映射到 `ExhibitDetailView.vue`、`ThreeExhibitViewer.vue` 和现有 CSS，不依赖新业务接口。
- 图片无损坏、主体裁切或明显文字乱码。

## 风险

- 图像模型仍可能轻微改变被蒙版边缘覆盖的像素或个别小字；最终实现必须使用真实 DOM 文案和组件。
- 本轮效果图用于选择桌面 UI 架构，移动端 Bottom Sheet 需在选定方向后单独深化。

## 验证结果

- 方案 C 因第三次图像生成请求遇到服务额度不足，改用原截图的中央 3D 场景和确定性 HTML/CSS 渲染；输出尺寸为 `2048 × 1136`。
- 三张最终 PNG 均已成功打开并完成原尺寸目视检查。
- A/B/C 均只使用现有功能；没有新增测量、标注、切面、对比或图层等概念功能。
- C 已核对中文、控件数量、选中状态和区域职责，可直接映射到现有 Vue 组件。
- 本轮未修改 Vue、CSS、Three.js、接口或业务逻辑，因此未运行前端类型检查、单元测试和生产构建。

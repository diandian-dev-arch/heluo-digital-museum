# 后台设计系统一致性收口计划

## 目标

让内容管理与运营管理复用同一套卡片、按钮、表单和导航规则，并与公共前台的月白玻璃、墨玉强调色和克制交互保持一致。

## 关联需求

- F-04/F-07/F-11/F-13：后台内容与运营管理
- N-03：响应式、易用性和视觉一致性
- N-06：共享组件和可维护性

## 影响范围

- `frontend/src/components/AdminShell.vue`
- `frontend/src/components/AdminActionButton.vue`
- `frontend/src/views/AdminContentView.vue`
- `frontend/src/views/AdminOperationsView.vue`
- `frontend/src/assets/main.css`
- `frontend/src/assets/interaction.css`

不修改 API、权限、表单字段、状态机或后台业务操作。

## 实施步骤

1. 统一后台侧栏、页面标题、统计摘要与工具栏的玻璃层级。
2. 去除运营表单内部重复的字段卡嵌套，复用全站输入、焦点、禁用和校验规则。
3. 新增共享后台操作按钮，统一图标、尺寸、语义色、按压和键盘焦点。
4. 统一内容列表、运营列表和趋势区的卡片圆角、边界、阴影与悬停反馈。
5. 验证内容与运营页全部标签、表单状态、关键操作、桌面和手机布局。

## 验收标准

- 两个后台页面的同类元素使用相同共享组件或样式令牌。
- 页面不再出现大卡内部嵌套一排装饰性字段卡的视觉重复。
- 主要、普通、危险操作在两个页面具有一致的尺寸、图标和状态反馈。
- `1433x746` 与 `390x844` 无横向溢出、文本遮挡或控制台错误。
- 类型检查、单元测试、生产构建和 Docker 正式页面回归通过。

## 验证结果

- `corepack pnpm typecheck` 通过。
- `corepack pnpm test -- --run` 通过：11 个测试文件、39 项测试全部通过。
- `corepack pnpm build` 通过；仅保留既有 VueUse 注释与 Three.js 大分包提示。
- Docker Compose 前端镜像重建并强制重建容器成功，`http://localhost:8088/` 返回 HTTP `200`。
- `1433x746`：`/admin` 与 `/admin/operations` 无横向溢出；共享操作按钮实际高度为 `38px`，统计容器圆角为 `8px`；七个运营标签均可切换，用户、预约时段、商品和 3D 展项表单字段等高，字段标签无嵌套卡片背景或边框。
- `390x844`：两页无横向溢出或文字截断；侧栏转为顶部品牌和双导航，运营宽表单转为单列，共享操作按钮实际高度为 `42px`。
- 浏览器回归未执行会写入数据的创建、删除或状态变更操作；本轮只验证展示、标签切换、布局和交互状态。

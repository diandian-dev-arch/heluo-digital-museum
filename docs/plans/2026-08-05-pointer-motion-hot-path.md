# 鼠标动效热路径优化

## 目标

在不改变现有双层光标、局部探照、3D 微视差和输入降级契约的前提下，减少高刷新率鼠标移动造成的 Vue 更新与微任务开销，保持光标跟手和可访问性行为。

## 关联需求

- F-01/F-02/F-03/F-05/F-09：公开前台与 3D 展项的指针反馈。
- N-03/N-06：交互性能、键盘/触控/媒体偏好降级。

## 影响范围

- `frontend/src/composables/usePointerMotion.ts`
- `frontend/src/components/PointerCursor.vue`
- 指针单元测试与项目状态文档。

## 实施与验收

1. 将仅供 RAF 读取的坐标/速度从 Vue 响应式状态拆为共享普通对象。
2. 对 `pointermove` 的 `nextTick` 续帧检查做单次排队，并仅在事件目标变化时重新解析光标意图。
3. 运行类型检查、指针相关单元测试、生产构建、`qa:pointer-pages` 与 `perf:pointer`。

验收标准：光标仍能在键盘切回鼠标后重新出现；按下、危险/操作态、pen/touch 系统光标和 static/restrained 降级不回归；不新增 RAF，且 `git diff --check` 通过。

## 风险

事件目标保持不变期间不重复解析意图；仅当 DOM 在同一节点上动态变更 `data-cursor` 时可能延迟到下一目标事件，当前页面没有该运行时变更。

## 验证结果

已完成：RAF 读取的坐标/速度拆为普通共享对象；续帧检查单次排队，组件卸载有 mounted 保护；光标意图仅在事件目标变化时重算，并在隐藏/混合输入时清空缓存。随后按项目组连续反馈完成视觉显著度增强与圆环尺度收口。全量 17 个测试文件 60 项通过，类型检查、生产构建、`perf:pointer` 14 项、`qa:pointer-pages` 16 组、`perf:pointer-size` 与 `git diff --check` 均通过。Docker Hub 超时后使用已验证的本地 `dist` 固化前端镜像，容器重建成功；线上 HTTP `200` 且 CSS 确认为 `28px`/`38px`/`42px`。

## 视觉显著度增强

根据项目组 2026-08-05 反馈，先提升桌面 full 档的视觉反馈；随后根据“圈圈太大”的实用性反馈收细光标几何尺寸。最终基础外环为 `28px`，链接/主操作态为 `38px`/`42px`；外环跟随时间常数保持 `96ms`，按实际跟随距离增加的弹性尺度限制在最高 `12%`。Surface 探照半径保持 `240px`，继续使用青玉色核心光和月白光域承担显著反馈，避免依赖大尺寸圆环。

边界保持不变：只使用 transform、opacity、background 与 box-shadow，不修改布局属性；`static`、coarse pointer、减少动态、高对比度和强制颜色仍关闭自定义光标与 Surface 动效，减少透明度仍关闭探照光。

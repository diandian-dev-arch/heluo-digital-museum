# 深墨玉毛玻璃一致性精修计划

## 目标

按首页参观路线、首页策展手记和数字展项信息面板三条浏览器标注，统一深色毛玻璃材质。卡片颜色需要更深，同时通过背景模糊、边缘反射和半透明层次保留通透感。

## 关联需求

- F-01：首页公共入口与策展内容。
- F-05：3D 展项展示与信息面板。
- N-03：响应式布局与移动可用性。
- N-06：视觉一致性与可访问降级。

## 影响范围

- `frontend/src/assets/main.css`
- `PROJECT_STATUS.md`
- `docs/01-requirements-traceability.md`

不修改 Vue 结构、业务数据、路由、GSAP 动画、Three.js 渲染或交互所有权。

## 实施步骤

1. 新增三块重点卡片共用的深墨玉玻璃令牌。
2. 统一半透明底色、边框、顶部高光、背景模糊和阴影。
3. 移除 3D 面板早期局部光斑差异，改用与首页一致的全幅反射层。
4. 保留减少透明度和高对比度模式的实色降级。
5. 完成类型检查、测试、生产构建、Docker 更新及桌面/手机页面回归。

## 验收标准

- 三块卡片使用相同的深色玻璃材质参数，颜色比当前更深。
- 背景仍可通过模糊和色彩变化被感知，不呈现纯色塑料板。
- 文字、图标和操作按钮保持清晰，无横向溢出或控件裁切。
- `prefers-reduced-transparency` 与 `prefers-contrast: more` 下取消模糊并使用高对比实色。

## 风险

- 深色底层可能降低次要文字可读性；回归时检查首页标签、3D 事实正文和返回按钮。
- 更强背景模糊会增加合成成本；只作用于三块既有玻璃，不新增动画或持续重绘。

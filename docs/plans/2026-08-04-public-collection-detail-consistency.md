# 前后台品牌与馆藏细节一致性计划

## 目标

统一前后台品牌馆印，并精修首页策展鼎图、馆藏专题阅读卡、搜索框与分类河图，使同类视觉元素遵循同一套月白玻璃、青玉强调与图片主导规则。

## 关联需求

- F-01/F-02/F-03：馆藏浏览、搜索与专题阅读
- F-04/F-13：后台内容与运营入口
- N-03/N-06：响应式、易用性与共享组件维护

## 影响范围

- `frontend/src/components/MuseumBrandSeal.vue`
- `frontend/src/App.vue`
- `frontend/src/components/AdminShell.vue`
- `frontend/src/views/HomeView.vue`
- `frontend/src/views/ExploreView.vue`
- `frontend/src/assets/main.css`

不修改 API、权限、搜索逻辑、内容数据或路由。

## 实施步骤

1. 提取前台馆印为共享组件，并在后台品牌区复用。
2. 使用已登记的透明青铜鼎主视觉替换首页旧鼎封面。
3. 将三张专题阅读卡统一为图片主导、底部玻璃信息层的等宽卡片。
4. 重做搜索输入组、清除与提交按钮状态，并提升分类河图玻璃层级。
5. 完成桌面、手机、类型检查、测试、构建与 Docker 正式页面回归。

## 验收标准

- 前后台馆印 SVG 只维护一份，尺寸和线条一致。
- 首页首张策展卡清晰呈现完整青铜鼎，不带突兀黑色展台。
- 三张专题阅读卡在桌面等宽、手机单列，图片与文字均清晰且无重叠。
- 搜索框具有明确搜索图标、焦点态、清除操作和提交按钮层级。
- 分类河图具有与全站一致的 `8px` 月白玻璃材质。
- `1433x746` 与 `390x844` 无横向溢出或文字截断。

## 验证结果

- `corepack pnpm typecheck` 通过。
- `corepack pnpm test -- --run` 通过：11 个测试文件、39 项测试全部通过。
- `corepack pnpm build` 通过；仅保留既有 VueUse 注释与 Three.js 大分包提示。
- Docker Compose 前端镜像重建并强制重建容器成功，`http://localhost:8088/` 返回 HTTP `200`。
- `1433x746`：后台馆印与前台导航馆印均为同一共享 SVG；首页首张策展卡使用透明青铜鼎主视觉；馆藏搜索框高度 `61px`、分类河图高度 `243px`、专题三卡均为 `409x382px`，圆角均为 `8px`，页面无横向溢出。
- `390x844`：搜索框宽度 `343px`，河图按移动规则隐藏；专题三卡均为 `343x390px` 单列，文字无截断，图片进入视口后全部加载，首页鼎图无横向溢出。
- 未执行会修改内容或业务数据的搜索提交、内容编辑和状态操作，仅验证展示、聚焦、滚动和响应式状态。

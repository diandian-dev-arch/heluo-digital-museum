# 扩展图片素材与原创青铜鼎 GLB 模型

- 日期：2026-08-01
- 状态：已完成制作，待 Three.js 前端验收
- 关联需求：A-01、A-02、F-05

## 目标

在已确认的“河洛文化 + 深墨绿 + 青铜金 + 宣纸米白 + 现代数字展厅”方向下，新增 5 件文物卡片封面、3 件文创商品卡图片，并使用 Blender 制作一件原创青铜鼎源文件与可供 Three.js 加载的 GLB 模型。

## 影响范围

- `assets/images/exhibits/`：5 张新增文物卡片图片。
- `assets/images/products/`：3 张新增文创商品卡图片。
- `assets/models/bronze-ding/`：Blender 源文件、GLB、封面图和资产说明。
- `docs/`、`PROJECT_STATUS.md`：资产台账、状态与验证记录。

## 交付与验收标准

1. 五张方形文物封面与三张方形商品图均具有统一的卡片视觉语言，且无文字、水印、真实馆藏标识。
2. Blender 源文件保留可编辑模型、材质和灯光；器物为原创概念设计，不复刻已知真实文物。
3. 导出的 GLB 可被 glTF 工具读取，包含一个可见网格、基础 PBR 材质和适合网页加载的体积。
4. 同时保留模型封面图、来源/用途说明和验证结果。

## 实施步骤

1. 按统一方形构图生成 5 张原创文物封面与 3 张文创商品图。
2. 在项目目录建立可追溯的图片资产台账。
3. 安装或定位 Blender，使用可重复执行的 Blender Python 脚本建立原创青铜鼎：器腹、口沿、双耳、三足、原创抽象纹样与 PBR 材质。
4. 保存 `.blend` 源文件，导出 `.glb`，渲染封面图。
5. 用 Blender 后台检查重新打开源文件与 GLB，记录对象数、文件大小和验证结果。

## 风险

- Blender 尚未在当前环境发现；若安装或运行受阻，本阶段将保留图片素材，并记录模型交付的技术阻塞。
- AI 图片与 3D 概念模型均不能命名为真实馆藏；最终展签、史实介绍必须另经资料核对。
- PNG 原图不直接用于生产，需要后续导出 WebP/AVIF 与响应式尺寸。

## 验证结果

- 已生成并保存 5 张新增文物封面和 3 张新增文创商品图片；每张均为 1254 x 1254 PNG。
- 已通过 Blender 5.2.0 LTS 创建、保存并重新打开 `source/heluo-bronze-ding.blend`：26 个场景对象、21 个模型对象、4 个材质。
- 已成功导出并重新导入 `export/heluo-bronze-ding.glb`：21 个网格、3 个导出材质，文件大小 296,080 字节。
- 已渲染并目视检查 `preview/heluo-bronze-ding-cover.png`。
- 未验证：Three.js 浏览器加载、交互、移动端性能和 WebP/AVIF 压缩；前端工程尚未创建。

# 数字展厅五套色彩 UI 概念计划

## 目标

在不修改现有 Vue、CSS、Three.js 和业务逻辑的前提下，为三足青铜鼎数字展厅输出五套可直接比较的桌面高保真效果图，重点验证色彩、材质、留白和信息层级。

## 关联需求

- F-05：3D 展项浏览
- N-03：兼容性与可访问性
- N-06：可维护性

## 影响范围

- 新增 `docs/design/exhibit-ui-concepts/` 下的独立静态原型、截图脚本、说明和 PNG 效果图。
- 不加载到生产路由，不修改前端运行时代码，不改变需求完成状态。

## 实施步骤

1. 保留全站导航、3D 主舞台、工具栏、展项信息、实体/点云、导览进度和视角缩略图。
2. 复用项目现有青铜鼎与月白展厅素材，建立五套低饱和配色方向。
3. 使用本地 Chrome 在 1600x900 固定视口截图。
4. 检查每张图的文字、重叠、溢出、器物完整性和品牌一致性。
5. 记录方案取舍并同步项目状态与需求追踪变更记录。

## 验收标准

- 输出 5 张 1600x900 PNG，且配色方向清晰可区分。
- 每张均保留核心功能结构与 `Cleveland Museum of Art · 1962.281` 来源。
- 无横向溢出、明显控件重叠或无法阅读的主要文字。
- 只新增设计交付物，不修改现有业务页面。

## 风险

- 静态图只验证视觉层级，不能替代真实 3D、键盘、触摸和动效验收。
- 效果图中的透明材质需在落地阶段结合浏览器性能与减少透明度偏好重新校正。

## 验证结果

- 本地 Chrome 固定 `1600x900` 视口生成 5 张 PNG，文件大小均大于 400 KB。
- 逐张目视检查通过：青铜鼎完整可辨，主要中文和来源文字清晰，工具、信息板和底部导览无重叠。
- 截图使用项目现有月白展厅与青铜鼎封面，不新增来源不明的器物素材。
- `git status --short` 显示本轮仅新增设计目录和本计划；未修改现有业务页面。
- 未验证：真实 3D 交互、移动布局、键盘、触摸、动效性能和辅助功能；须在选定方向进入实现阶段后验收。

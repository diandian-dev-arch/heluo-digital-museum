# 数字展厅背景连续性修复计划

## 目标

移除数字展厅窗景上产生矩形马赛克观感的局部模糊遮罩，使背景建筑、玻璃与远景保持自然连续，同时不改变青铜鼎、Three.js、点云、信息面板和 Dock 的功能与构图。

## 关联需求

- F-05：数字展项展示
- N-03：视觉可用性与响应式
- N-06：前端可维护性

## 影响范围

- `frontend/src/views/ExhibitDetailView.vue`
- `frontend/src/assets/main.css`
- 不修改背景图片、3D 模型、相机、灯光、点云状态机或业务接口。

## 实施步骤

1. 删除固定在窗景上的矩形 `exhibit-background-glass` 装饰节点。
2. 删除对应桌面、移动和高对比度样式，保留场景全幅柔光渐层。
3. 运行前端检查、构建并在正式 Docker 页面复核桌面与手机布局。

## 验收标准

- 红框区域不再出现矩形模糊、低饱和色块或清晰直边。
- 背景窗景从鼎右侧到信息面板下方连续自然。
- 鼎、信息面板、Dock、实体/点云切换和手机布局不受影响。
- 类型检查、测试、构建及正式页面控制台检查通过。

## 验证结果

- `corepack pnpm typecheck`：通过。
- `corepack pnpm test -- --run`：11 个测试文件、39 项测试全部通过。
- `corepack pnpm build`：通过；仅保留既有 Three.js 分包超过 500 kB 的提示。
- Docker 前端镜像构建、容器重建成功，`http://localhost:8088/` 返回 `200 OK`。
- `1433x746` 正式页面截图确认矩形模糊层已消失，窗框、远景、地面和远处展品连续显示；页面无横向溢出。
- `390x844` 正式页面无遮罩残留和横向溢出；桌面与手机控制台均无警告或错误。

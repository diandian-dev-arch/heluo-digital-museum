# 青铜鼎选定质感优化实施计划

## 目标

参照用户确认的效果图，将数字展厅中的青铜鼎调整为灰绿古青铜：保留铸造颗粒、浅浮雕、局部氧化和磨损边缘，同时控制金属反射与高光，避免再次过曝或变成无细节的黑色剪影。

## 实施范围

- 只调整 `ThreeExhibitViewer.vue` 的 GLB 材质运行时预设。
- 复用当前 v5.3 GLB 内嵌 Base Color、Normal、Metallic-Roughness 和 AO 贴图，不引入外部运行时资源。
- 保留黑石金线底座、相机位置、实体/点云切换、视角、旋转/缩放/复位和资源释放逻辑。

## 视觉策略

- 使用轻微灰绿中性色调，让原始古铜贴图向效果图的青灰绿方向收敛。
- 适度提高环境反射，保留粗糙金属的柔和高光。
- 放宽过度粗糙限制并控制金属度，增强纹饰明暗层次而不产生塑料感。
- 提升法线贴图表现，突出铸造颗粒和浅浮雕细节；不使用自发光。

## 验收标准

- 青铜鼎整体呈灰绿古铜色，纹样、器腹、双耳和三足清晰可辨。
- 明部有柔和金属反射，暗部仍保留颗粒和氧化细节。
- 刷新首帧、实体/点云切换和不同预设视角均不出现白闪、纯黑或材质丢失。
- 类型检查、测试、生产构建和 Docker 前端服务检查通过。

## 验证结果

- 已建立灰绿古青铜运行时材质预设：轻微灰绿校色、适度环境反射、柔和粗糙金属高光和增强法线细节。
- 已保留 v5.3 GLB 内嵌 PBR 贴图与所有展厅交互，不新增外部运行时素材。
- `pnpm typecheck`、`pnpm test -- --run`、`pnpm build` 通过；Docker 前端重建与 HTTP 200 检查通过。
- 未执行真实登录态下的数字展厅截图复核；需在浏览器保持有效会话后补充最终视觉验收。

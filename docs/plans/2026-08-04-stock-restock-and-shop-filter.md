# 商品补货与商城分类交互

## 目标

为管理员提供已有商品的库存补货入口，并让商城商品分类按钮可切换筛选；同时收紧数字展厅首屏顶部留白。

## 实现

- 新增管理员库存专用 PATCH 接口，库存不得低于已锁定库存，并写入操作日志。
- 后台商品列表增加“补货”操作和库存编辑表单。
- 商城分类按钮改为可访问的状态切换，并按现有商品 slug 映射分类。
- 数字展厅 intro 顶部间距收紧。

## 验收

- 前端类型检查、测试、生产构建通过。
- 后端 Maven 测试通过。
- Docker backend/frontend 重建并启动，商城和产品 API 返回 200。

## 验证结果

- 提交前审查将两个库存写入口收紧为数据库原子条件更新，结算并发增加 `locked_stock` 时不会写入更低的总库存。
- 新增管理员库存接口集成测试，覆盖低于锁定库存返回 `409` 且原值不变，以及合法库存更新成功。
- `mvn test`：12 项通过，空 H2 数据库成功执行 Flyway V1–V20。
- `pnpm typecheck`、17 个测试文件 60 项、`pnpm build` 通过；指针性能、体积和 16 组页面映射门禁通过。
- 提交前两次尝试重建 backend 镜像，均因 Docker Hub 连接超时而在获取构建前端/基础镜像时停止，未执行项目 Dockerfile，也未替换现有后端容器；此前实现阶段的 Docker 验证记录保持有效，本次原子更新仍待镜像网络恢复后复验。

# Apple Design 前台优化实施计划

- 日期：2026-08-01
- 状态：核心实现完成，待全量验收
- 关联需求：F-01、F-02、F-03、F-05、F-06、F-09、F-10、F-12、N-03、N-06
- 设计基线：保留“当代东方数字策展”，引入 Apple Design 的响应、材质层级、可中断动效和移动端手势。

## 目标

覆盖五个核心前台页面、内容详情、登录注册和个人中心；不改后端 API、数据库、业务状态机或后台管理界面。通过 `motion-v` 统一按压、布局、路由和 Sheet 动效，保持真实 API 数据和 Three.js 交互。

## 实施范围

- 全局 Motion 令牌、减少动态/透明度/高对比度支持、焦点和 44px 触控目标。
- 桌面吸顶半透明导航、移动端五项底部导航、路由交叉过渡。
- 首页、馆藏、3D 展项、预约、商城的交互反馈和移动端重排。
- 内容详情、登录注册、个人中心的统一表单和异步状态。
- Three.js 相机视角过渡、移动端展项信息 Sheet、路由懒加载和 Three.js 分包。

## 已完成实现

- `motion-v` 已加入前端依赖并写入锁文件；根节点启用 `MotionConfig reducedMotion="user"`。
- 新增 `FluidButton`、`InlineStatus`、`BottomSheet` 和移动端五项底部导航；导航与路由内容增加透明材质、交叉淡入和安全区适配。
- 首页、馆藏、预约、商城接入按压/布局/渐入反馈；商城移动端购物车、预约移动端信息、3D 展项移动端信息使用可关闭 Sheet。
- Three.js `setView` 支持 `{ animated?: boolean }`，默认视角动画可被 OrbitControls 的拖拽立即接管；初始化和减少动态模式使用立即定位。
- 内容详情加入阅读进度指示；登录、注册、个人中心和预约状态改用共享 `InlineStatus`；核心前台路由改为懒加载。

## 验收标准

- `1630×965`、`1672×941`、`1440×900`、`768×1024`、`390×844` 无关键横向溢出，原有东方视觉基线不被 Apple 化覆盖。
- 快速重复操作时动效可中断；3D 视角切换过程中重新拖拽立即接管；Sheet 支持三段吸附和 ESC 关闭。
- 键盘、触摸、减少动态、高对比度和减少透明度设置下均可完成核心流程。
- 搜索、分类、预约、登录、购物车数量、订单和模拟支付业务保持可用。
- `pnpm typecheck`、`pnpm test`、`pnpm build`、Docker 服务和浏览器核心流程通过。

## 风险

- `motion-v` 增加少量前端依赖和产物体积；通过路由懒加载避免普通页面预加载 Three.js。
- 移动端底部导航和购物车 Sheet 属于交互结构调整，需要重点做键盘焦点和安全区回归。
- 当前工作区存在其他未提交业务与素材改动，本任务不重置或覆盖无关文件。

# 2026-08-02 商城器物工作室与购物袋重构

## 目标

将公开商城桌面端按已确认效果图重构为器物工作室陈列与右侧白色购物袋抽屉。商品、库存、登录跳转、购物车数量、数量调整、移除和模拟支付逻辑保持不变。

## 关联需求

F-09、F-10、F-12、N-03、N-06。

## 改动

- 新增无文字器物工作室环境图；它只展示商品展台与环境，所有标题、价格、库存、按钮和购物袋内容均由真实 Vue DOM 与 API 数据渲染。
- 桌面端左侧以统一展台背景承载三件商品的真实操作点，右侧重构为固定、分隔清晰的购物袋抽屉。
- 移动端继续使用现有 BottomSheet，不引入桌面抽屉的关闭假交互。

## 验收

- 购物车空态、登录提示、有商品数量、移除和结算保持原行为。
- 通过 `pnpm typecheck`、`pnpm test`、`pnpm build` 与 Docker 前端重建。

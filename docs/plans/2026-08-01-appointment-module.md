# 预约模块实施计划

- 日期：2026-08-01
- 状态：本轮修复已完成
- 关联需求：F-06、F-07、F-08、N-01、N-02、N-03。

## 目标

让已登录用户能够查看开放时段、提交预约、查看和在开始前两小时取消自己的预约；让管理员维护时段、确认、取消和完成预约。所有名额修改在事务内完成，状态变化写入操作日志并触发开发邮件捕获通知。

## 验收

- 公开时段只显示未来、开放且未满的时段；用户只能读取和取消自己的预约。
- 创建、取消、管理员确认/取消均正确维护 `reserved_people`；开始前两小时后用户不可取消。
- 状态只允许 `PENDING → CONFIRMED/CANCELLED`、`CONFIRMED → COMPLETED`；管理员取消可处理待确认或已确认预约。
- 非管理员不能调用后台预约接口；状态通知不会回滚已经成功的预约状态变更。

## 本轮修复验证（2026-08-01）

- 过期参观日期由后端直接拒绝，返回 `409 Conflict` 和“参观日期不能早于今天”；失败时不会占用时段名额。
- 前端预约页按 401、409、422 和加载/提交失败分别显示可理解的中英文提示。
- 后端集成测试通过：`mvn test`，6 个测试全部通过。

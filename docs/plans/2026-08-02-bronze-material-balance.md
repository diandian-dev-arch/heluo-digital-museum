# 数字展厅青铜材质平衡修复

## 目标

在不恢复刷新过曝的前提下，提高青铜鼎实体模型的可读性，让纹饰、金属反射和古铜质感能够在月白展厅中被看见。

## 调整范围

- 适度提高环境反射、半球光、主光、侧补光和背光。
- 增加低强度正面柔光，补足器腹和足部暗部。
- 将 GLB 材质环境反射提高到中等水平，降低过度粗糙限制，保留古铜的漫反射层次。
- 不修改模型文件、相机位置、点云颜色、接口或交互逻辑。

## 验收标准

- 器物轮廓、饕餮纹饰和三足结构清晰可见。
- 高光不形成整块白斑，背景和展台仍保持月白视觉。
- 实体/点云切换、旋转、缩放、复位与资源释放逻辑不受影响。

## 验证结果

`pnpm typecheck`、`pnpm test -- --run`（3 个测试文件、7 项测试）和 `pnpm build` 通过；构建保留既有 `@vueuse` PURE 注释与大分包警告。Docker 前端重建与 HTTP 200 检查待执行。

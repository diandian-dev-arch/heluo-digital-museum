# Three.js 博物馆级点云展项实施计划

- 日期：2026-08-01
- 状态：已实施并完成前端验证
- 关联需求：F-05、A-02、N-03、N-06
- 视觉基准：`assets/design-mockups/2026-08-01-threejs-pointcloud-exhibit/`

## 目标

在现有自主创作的 `heluo-bronze-ding-v4.glb` 上实现实时点云模式：首次进入由离散粒子在约 1.8 秒内聚合为 PBR 实体，用户可切换“实体/点云”、重置视角，并在低性能设备获得可理解的实体降级。

## 影响范围与决定

- `frontend/src/components/ThreeExhibitViewer.vue`：GLB、MeshSurfaceSampler、GPU ShaderMaterial、展厅场景、Bloom、资源释放。
- `frontend/src/views/ExhibitDetailView.vue` 与 `frontend/src/assets/main.css`：深墨绿环形展厅、玻璃说明面板和响应式操作界面。
- `frontend/src/lib/pointCloudQuality.ts`：可单测的画质分档和性能降级规则。
- 不新增后端 API、数据表、权限或大型依赖。

## 实现步骤

1. 按屏幕尺寸、触摸指针、CPU 核心数和可用内存划分高/标准/移动画质：120,000、60,000、24,000 点；高画质启用轻度 Bloom。
2. 遍历 GLB 网格，以表面积分配采样预算；`MeshSurfaceSampler` 生成 `position`、`aOrigin`、`aColor`、`aSeed` 属性。
3. 用 GPU 在离散起点和文物表面之间插值，首次动画 1,540ms 聚合、260ms 与实体交叉淡入；手动模式切换约 650ms。
4. 用实时 Three.js 地面、展台、圆环、环形墙、展柜光盒和灯光还原展厅；说明文字和按钮保留为可访问的 HTML/CSS。
5. 若 2.5 秒窗口内平均帧率低于 35：高画质降为标准并关闭 Bloom；标准/移动则回到实体模式。减少动态效果用户跳过入场动画，WebGL 或模型失败时展示封面图。

## 验收标准

- GLB 可加载、旋转、缩放、双击或按钮重置；失败时展示封面和重试。
- 首次进入形成“离散粒子 → 聚合 → 实体”的连续过程；实体/点云重复切换无重载模型和明显闪烁。
- 点云颜色来自 GLB PBR 材质，金色游尘保持克制，不出现亮绿色主色。
- 页面离开后取消动画、释放几何体、材质、纹理、控制器、合成器和 renderer。
- 类型检查、Vitest、生产构建和浏览器桌面/移动端验收均通过后，更新状态和追踪记录。

## 风险

- 当前 v4 模型的纹饰精度低于视觉基准；实时点云和展厅效果完成后，精修 Blender 模型和 PBR 贴图应作为独立资产任务。
- 运行时帧率随设备与浏览器显卡能力而变化；页面实施“优先可用”的一次性降级而不是强制维持视觉特效。

## 验证结果（2026-08-01）

- `pnpm typecheck`：通过。
- `pnpm test`：2 个测试文件、3 个测试通过；新增画质分档与降级路径单元测试。
- `pnpm build`：通过；Three.js、GLTFLoader、MeshSurfaceSampler 与 Bloom 均按需分包。
- 浏览器桌面验收：使用实际 GLB 验证深墨绿/青铜金展厅、首次聚合、实体/点云切换、右侧模式与画质指示、旋转/缩放/重置控制；控制台无 error。
- 移动端：以 390px 触摸视口验证自适应路径；在持续低帧率时会禁用点云并保持实体可浏览，满足“优先可用”的降级策略。
- 本轮失败降级修复：模型加载失败和初始化异常均显示封面、文字说明与重试入口，并为加载层/失败层补充可读状态；未强制破坏线上数据来伪造失败，失败分支以源码检查和生产构建验证。
- 本轮响应式修复：桌面浏览器（1280px）和 390px 移动视口均验证实际 GLB 可加载、无横向溢出；前端 Docker 服务已重建并运行。
- 浏览器验收使用前端 API mock 提供已发布展项数据；本机 Spring Boot 未能启动是因为本地 MySQL 未运行，未影响前端构建与 GLB WebGL 验证。

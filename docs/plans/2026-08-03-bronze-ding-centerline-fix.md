# 青铜鼎中轴纹样校正计划

## 目标

修复三足青铜鼎正面中轴浮雕下段向右偏移的视觉问题，保持器身、双耳、三足和材质不变。

## 关联需求

- F-05：游客可进入 3D 展厅查看并操作已发布展项。
- N-03：桌面和移动端核心操作可用。
- N-06：3D 交互实现可测试、可维护。

## 影响范围

- `assets/models/bronze-ding/source/`：在 v5.4 源文件基础上生成可回退的修正版。
- `assets/models/bronze-ding/export/`：新增修正版 GLB。
- `frontend/public/media/models/`：更新实际运行时模型。
- 如模型文件名或大小发生变化，同步更新模型资产台账和后端迁移记录。

## 实施步骤

1. 检查 v5.4 网格坐标和正视渲染，定位中轴浮雕的局部范围。
2. 在源文件副本中仅对正面中轴纹样下段做小幅 X 轴反向校正，不旋转整只鼎。
3. 导出修正版 GLB，保留 v5.4 原文件作为回退。
4. 更新运行时资产、资产说明和项目状态。
5. 运行 Blender/GLB 校验、前端类型检查、测试、生产构建和页面回归。

## 验收标准

- 正视图中轴纹样从上沿到底部视觉上保持竖直。
- 侧视、背视、点云模式、旋转和缩放不回归。
- 模型加载地址返回 200，GLB 可被 Three.js 正常解析。
- 相关前端检查和生产构建通过。

## 风险

- v5.4 来自第三方 CC0 原始网格，局部校正属于项目派生处理；保留原始模型和 SHA-256 记录，不覆盖只读来源资产。
- 若局部选择范围不准确，可能影响相邻纹样；通过正视、侧视和网页截图复核后再采用。

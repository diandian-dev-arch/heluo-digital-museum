# 首批视觉概念与青铜鼎主题素材

- 日期：2026-08-01
- 状态：已完成首轮候选素材，等待项目组确认视觉方向
- 关联需求：A-01（图片自主创作）、A-02（3D 展项自主创作）、F-05（3D 展项展示）

## 目标

建立可见、可讨论的河洛数字博物馆视觉基线，并交付首件“原创河洛风格青铜鼎”主题的首页、文物与文创图片候选素材；本阶段不制作真实历史文物复原，不导出 GLB 模型，也不接入前端。

## 影响范围

- 新增：`assets/images/concepts/2026-08-01/`
- 新增：首批 6 张 PNG 概念/候选素材及该目录的 `README.md`
- 更新：`PROJECT_STATUS.md`、`docs/01-requirements-traceability.md`
- 不涉及：前后端代码、数据库、接口、依赖、部署配置

## 创作方向

- 文化意象：河洛水系、抽象古代几何纹样、原创器物轮廓。
- 色彩：深墨绿、氧化青铜、克制古金、宣纸米白。
- 空间：现代数字展厅，而非宫殿式场景。
- 资产边界：所有青铜鼎均为原创概念器物，不表示、命名或复原任何真实馆藏。

## 执行步骤

1. 生成首页与文物详情页视觉方向图，验证配色、信息层级和页面氛围。
2. 生成 Three.js 展厅氛围方向图，确定单展品、环形展台、轻量互动信息层的展示思路。
3. 生成青铜鼎主题的首页横幅、文物封面和文创商品卡候选图。
4. 将图片复制到项目资产目录，并在 `README.md` 登记用途、尺寸、创作方式与后续限制。
5. 由项目组确认后，再开始：WebP/AVIF 导出、裁切规格、其余图片清单、Blender 源文件及 GLB 模型制作。

## 验收标准

- [x] 可直观看到首页、详情页、3D 展厅的统一视觉效果。
- [x] 交付青铜鼎主题的首页主视觉、文物卡片封面、文创商品卡图片各 1 张。
- [x] 图片已保存到项目内，且有用途和限制说明。
- [ ] 项目组确认视觉方向、展品命名与是否作为正式素材。
- [ ] 形成完整图片清单并完成 Web 性能优化。
- [ ] 保留 Blender 源文件并导出可被 Three.js 加载的原创 `.glb` 模型。

## 风险与后续

- 当前 PNG 约 1.8–2.7 MB/张，不能原样全部放入生产网页；接入前需按实际容器尺寸裁切、转 WebP/AVIF，并以懒加载方式使用。
- 视觉方向图含抽象 UI 线条，不可被当作最终可开发 UI 标注；页面文案与组件布局应以用户故事和后续页面设计为准。
- AIGC 图片仅是二维视觉素材；它不能替代 Blender 源文件或 GLB 交付物，故 A-02 仍处于设计中。

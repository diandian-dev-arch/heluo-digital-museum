# 全站前端视觉精修实施计划

- 日期：2026-08-01
- 状态：核心实现与浏览器回归完成
- 关联需求：F-01 至 F-13、N-03、N-06
- 设计基线：保留“当代东方数字策展”、原创素材、青铜鼎 v5、Three.js 与现有业务契约。

## 目标

统一前后台视觉语言：首页与 3D 展厅强化品牌记忆点，其他前台页面补齐组件和响应式一致性，后台升级为同品牌的高密度专业工作台。消除路由懒加载空白、重复装饰标签、表单仅依赖占位符和状态表达不一致等问题。

## 影响范围

- `frontend/`：全局视觉令牌、共享按钮/状态/骨架/后台壳层、前台与后台页面样式和可访问标记。
- 文档：本计划、项目状态和需求追踪表。
- 不改后端 API、数据库、鉴权、路由地址、订单/预约状态机或素材版权记录。

## 实施步骤

1. 统一颜色、间距、字体、圆角、阴影、动效和层级令牌，补齐共享控件状态。
2. 精修首页、3D、馆藏、预约、商城、详情、认证和个人中心；为异步路由提供非空白骨架。
3. 建立后台壳层、紧凑概览、状态徽标和标签化表单，保留现有请求与操作逻辑。
4. 运行类型检查、单元测试和生产构建；在指定桌面、平板与手机尺寸执行浏览器回归。
5. 更新项目状态与需求追踪，审查差异后等待用户确认提交。

## 验收标准

- `1672×941`、`1630×965`、`1440×900`、`768×1024`、`390×844` 无关键横向溢出、文字截断或浮层遮挡。
- 前后台按钮、表单、状态、焦点、加载和空状态使用统一语义；主要触控目标不小于 44px。
- 路由懒加载有可见骨架；减少动态、减少透明度和高对比度模式不影响核心流程。
- 游客、用户、管理员核心浏览器流程保持可用；`pnpm typecheck`、`pnpm test`、`pnpm build` 通过。

## 风险

- 当前工作区包含大量未提交业务与素材改动，本轮只编辑前端视觉相关文件和项目文档，不重置其他改动。
- Three.js 与字体产物体积警告属于既有风险；本轮不新增大型依赖。
- 后台结构视觉变化较大，必须重点验证窄屏导航、长表单与危险操作的可辨识性。

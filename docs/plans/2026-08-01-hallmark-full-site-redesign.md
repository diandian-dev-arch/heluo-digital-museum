# Hallmark 前后台全站大胆重做实施计划

## 目标

以“东方编辑策展”为统一系统，大幅重做前台与后台的结构节奏、视觉层级和交互状态，保持既有路由、API、权限、Three.js、预约、订单与模拟支付能力不变。

## 关联需求

F-01～F-13、N-03、N-06、A-01、A-02。

## 影响范围

- 新增根目录 `design.md` 与 `.hallmark` 预检、运行记录。
- 调整前端全局样式、路由元数据、应用壳层、现有页面和共享组件。
- 同步项目状态和需求追踪；不修改后端接口、数据库与部署契约。

## 步骤

1. 锁定河洛纸墨主题、字体、间距、动效与响应式规则。
2. 合并全局令牌，补齐输入、按钮、状态、焦点和媒体偏好。
3. 重做首页、馆藏、展厅、详情、预约、商城、账户和后台工作台。
4. 执行类型检查、单元测试、生产构建、五档响应式和三角色业务回归。
5. 实际重建 Docker 前端，核对服务、HTTP、控制台和 Git diff。

## 验收标准

- 320/375/414/768/1440px 无横向滚动、交互文字异常折行或底部导航遮挡。
- 游客、用户和管理员核心流程保持可用，API 契约未变化。
- `pnpm typecheck`、`pnpm test`、`pnpm build` 通过。
- Docker 前端服务实际重建且 HTTP 可访问；浏览器控制台无新增错误或警告。
- 键盘焦点、减少动态、减少透明度与高对比度具备明确降级。

## 风险

- 当前工作树包含大量既有未提交成果；只增量编辑，不删除文件或执行全项目格式化。
- 本地字体和 Three.js 仍可能产生构建体积提示，须与功能错误区分记录。
- 后台全量视觉验收依赖管理员测试账号和后端服务可用。

## 验证结果

- `pnpm typecheck`：通过。
- `pnpm test`：3 个测试文件、7 项测试全部通过。
- `pnpm build`：通过；仅保留 `@vueuse/core` PURE 注释清理和大分包提示，无构建失败。
- 生产版在 320/375/414/768/1440px 对首页、馆藏、展厅、预约、商城、登录、内容后台和运营后台完成自动化布局检查；页面标题、`zh-CN`、横向溢出均通过。
- 3D 展项生产版加载 1 个 WebGL 画布，无加载/失败降级残留，无横向溢出；最终新标签页控制台无错误或警告。
- 可见键盘焦点通过：品牌链接获得 2px 实线焦点环和 2px 外偏移；CSS 已实现减少动态、减少透明度与高对比度媒体降级。
- 游客浏览/3D、普通用户登录/预约/购物车/模拟支付、管理员确认预约/完成订单/核心运营页面均走通；本轮创建的 QA 预约和订单测试数据已在本地数据库完成闭环。
- `docker compose --env-file .env.example build frontend` 与前端容器重建通过；前端 HTTP 200，`/api/v1/health` 正常，公开展项、馆藏和预约时段接口可读。
- 未验证：真实手机触摸性能、实体设备系统级减少动态/透明度/高对比度体验；保留为项目验收项。

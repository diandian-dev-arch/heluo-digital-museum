# 公开页面导航、卡片与表单统一精修计划

## 目标

根据首页、馆藏、数字展厅列表、预约和商城的浏览器标注，统一导航、卡片、表单和按钮的视觉层级，提升展品图片可读性并避免文字被复杂背景遮挡。

## 关联需求

- F-01/F-03：馆藏浏览与详情入口
- F-05：数字展厅入口
- F-06：预约表单
- F-09：商城商品与购物车入口
- F-12：中英文导航
- N-03/N-06：响应式、可用性和工程验证

## 影响范围

- 全站公开页顶部导航与语言切换
- 首页路线卡、策展卡、器物卡和参观路线卡
- 馆藏器物卡与专题阅读卡
- 数字展厅列表首屏介绍区
- 预约桌面表单与参观人数控件
- 商城商品信息卡和加购按钮
- 相关响应式、减少透明度和项目文档

## 实施步骤

1. 重整顶部导航的玻璃材质、当前态、工具区和语言切换。
2. 将首页策展区域从表格式分隔改为等高、清晰分组的策展卡。
3. 降低馆藏卡遮罩强度，将文案收敛为底部信息条，扩大展品图片可见区域。
4. 压缩数字展厅介绍区无效留白，保持首屏可见展项内容提示。
5. 将预约输入字段改为统一字段面板，强化焦点、占位符与人数步进控件。
6. 为商城商品文案增加独立可读底板，统一价格、库存和加购按钮。
7. 运行工程检查、Docker 重建和桌面/手机多路由浏览器回归。

## 验收标准

- 导航栏品牌、主导航、语言和账号入口层级清晰，当前态不依赖红色方框。
- 首页五张策展相关卡片等高、信息不拥挤，路线卡细节统一。
- 馆藏五张器物卡能直接辨认展品主体，深色遮罩不覆盖大部分图片。
- 专题阅读卡片图片与文案比例协调。
- 数字展厅列表首屏不再出现大面积无信息留白。
- 预约字段、文本域和人数控件具有统一边界、焦点和触控高度。
- 商城文字不被背景图干扰，三个加购按钮一致且反馈明确。
- `1433x746` 与 `390x844` 无关键横向溢出或控件遮挡。

## 风险

- 多页共享 CSS 覆盖层较多，新增规则必须放在最终覆盖层并限制到目标页面。
- 放大馆藏图片可见区域时必须保留标题、分类和详情入口的对比度。
- 商城采用全幅背景，信息底板需克制，不能遮住主要商品图。

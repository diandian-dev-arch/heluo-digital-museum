# Apple 毛玻璃界面精修实施计划

## 目标

在不改变前后端业务契约、权限、订单、预约和 3D 逻辑的前提下，统一首页、馆藏、商城购物袋、登录页与后台看板的视觉材质和即时反馈，延续“河洛纸墨”的当代东方策展风格。

## 关联需求

- F-01、F-02、F-03：馆藏浏览、搜索与详情入口
- F-04、F-13：内容管理与运营统计看板
- F-08：登录、注册与密码找回
- F-09、F-10：购物袋、订单与模拟支付入口
- N-03：响应式、可访问性、表单与状态反馈
- N-06：类型检查、测试、构建与实施记录

## 影响范围

- 全局指针意图识别及其单元测试
- 首页路线玻璃卡、统一图标与底部 CTA
- 馆藏页筛选、器物卡和专题阅读卡
- 商城未登录/空购物袋状态
- 登录页背景与表单玻璃层
- 内容管理和运营管理的统计、表单、列表、趋势卡与按钮

## 实施步骤

1. 修复普通标题和正文被错误判定为原生光标区域的问题，并补充同类元素测试。
2. 将首页路线字符图标替换为统一线性图标，精修玻璃层级、悬停与 CTA。
3. 为馆藏页和购物袋空状态建立克制的月白玻璃材质，保持原有内容结构。
4. 将登录页改为现有博物馆大图背景，表单叠加深墨绿半透明玻璃层。
5. 统一两个后台看板的色彩、数字、卡片、表单和按钮状态。
6. 运行前端类型检查、单元测试、生产构建、指针性能门禁和桌面/移动浏览器回归。

## 验收标准

- 普通文字区域上的自定义指针和环境动效不中断；输入、下拉和画布仍使用原生交互。
- 首页三个路线图标风格、尺寸和对齐一致，两个 CTA 有清晰的悬停、按压和键盘焦点反馈。
- 馆藏卡片为圆角不超过 8px 的半透明玻璃材质，文字可读且无卡片套卡片。
- 商城空状态层级清晰，登录入口可识别并可键盘访问。
- 登录、注册、找回和重置模式在桌面与手机上均无溢出，背景图和表单对比度可靠。
- 内容与运营后台使用同一材质、字体色和按钮体系，统计数字采用清晰的等宽数字特性。
- 相关检查通过，目标页面无横向溢出、无控制台错误、无文字遮挡。

## 风险

- `main.css` 存在多阶段覆盖规则，本轮使用页面作用域选择器并在末尾集中收口，避免影响 3D 与业务组件。
- 毛玻璃依赖浏览器支持；为减少透明度或高对比度偏好提供更实的降级背景。
- 后台生产回归需要管理员身份，只从本地忽略配置读取凭据，不记录或提交。

## 验证结果

- `corepack pnpm typecheck`：通过。
- `corepack pnpm test`：10 个测试文件、38 项测试全部通过。
- `corepack pnpm build`：通过；保留既有字体和 Three.js 大分包提示。
- `corepack pnpm perf:pointer`：14 项门禁全部通过，普通馆藏路由未加载 Three.js，CPU 4x 低帧率可降级。
- Docker：前端镜像成功重建并在 `http://localhost:8088` 运行。
- 桌面 `1433x746`：`/`、`/explore`、`/shop`、`/login`、`/admin`、`/admin/operations` 无横向溢出；两个后台的统计数字字体和颜色一致；控制台无错误或警告。
- 手机 `390x844`：首页、馆藏、登录、内容后台和运营后台无横向溢出、文字遮挡或卡片越界；登录表单可继续纵向滚动适配更多字段。
- 指针实测：首页标题区域的 `.pointer-cursor` 保持 `data-intent="idle"`、`is-visible`，不再因普通文字消失。
- 辅助模式：浏览器启用减少透明度时，玻璃面板正确回退为高对比实色背景。

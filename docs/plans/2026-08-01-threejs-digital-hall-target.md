# Three.js 数字展厅目标效果实施计划

- 日期：2026-08-01
- 状态：设计已确认，等待前端工程阶段实施
- 关联需求：F-05、A-02、N-03、N-06
- 视觉依据：用户确认的“深色环形数字展厅 + 中央青铜鼎 + 暖金聚光 + 右侧半透明信息面板”效果图。

## 目标

在网页端实现该效果图的核心体验：进入 3D 展厅时看到深色环形展厅、中央展台与青铜鼎；用户可围绕文物旋转和缩放；右侧信息面板、加载状态和预约入口保持清晰可操作。

## 实现策略：3D 场景 + Web UI 混合

不把整张效果图作为不能互动的背景图。采用以下分层：

1. **Three.js / WebGL 层**：青铜鼎 GLB、圆形展台、地面、环形墙面、展柜轮廓、河洛流线装饰、金色光环、阴影和暖色聚光。
2. **Vue / HTML / CSS 层**：右侧半透明说明面板、标题/年代/材质信息、旋转缩放提示、预约按钮、加载/失败/设备不支持提示。
3. **性能降级层**：低性能或不支持 WebGL 时，展示同构图静态封面和文字内容，仍可阅读与预约。

这样既接近目标视觉，又不会把交互、文本和业务按钮画死在图片中。

## 关键技术

- `three`：`Scene`、`PerspectiveCamera`、`WebGLRenderer`、`GLTFLoader`、`OrbitControls`。
- 色彩与渲染：`SRGBColorSpace`、`ACESFilmicToneMapping`、阴影、暖色 `SpotLight`、弱环境光和受限 Bloom。
- 交互：限制旋转角度、缩放范围和阻尼；仅旋转青铜鼎观察，不让用户迷失在展厅中。
- 资源：GLB 使用标准 PBR 材质；模型、背景纹理与封面按需加载；离开页面时释放纹理、几何体、材质和 WebGL renderer。
- 响应式：桌面端右侧面板悬浮；手机端改为底部抽屉，降低渲染分辨率和场景细节。

## 分阶段实施

1. 前端工程创建后，先加载 GLB，完成旋转、缩放、加载与失败状态。
2. 加入基础展台、深色展厅、三盏灯与色彩管理，先使网页端材质和色调接近目标图。
3. 加入环形墙面、展柜、河洛线条和金色灯带；控制总资源与首屏加载。
4. 用普通 HTML/CSS 制作右侧说明面板和操作入口。
5. 完成桌面/移动端、WebGL 不支持、加载失败及资源释放验收。

## 验收标准

- 初次进入 3D 展厅即可看到与目标图相同的“中央文物 + 深色展厅 + 暖金聚光 + 右侧说明”构图。
- 用户可旋转、缩放文物；操作不会使相机穿墙或迷失。
- 模型加载、加载失败和不支持设备均有明确提示和静态降级图。
- 手机端可浏览信息、返回和预约；退出页面后 WebGL 资源得到释放。
- 浏览器端验收通过后，才将 F-05/A-02 标为已完成。

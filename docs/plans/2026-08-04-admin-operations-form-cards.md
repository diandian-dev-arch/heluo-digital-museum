# 运营后台表单字段卡精修计划

## 目标

修复创建普通用户表单中初始密码输入框与其他控件不对齐的问题，并统一创建用户、预约时段、商品和 3D 展项表单的字段卡高度与视觉层级。

## 关联需求

- F-11/F-13：后台运营管理与统计工作台
- N-03：表单易用性和响应式
- N-06：工程检查与实施记录

## 影响范围

- `AdminOperationsView.vue` 的初始密码标签结构
- `main.css` 中后台运营表单字段卡、输入控件和按钮对齐样式
- 项目状态与需求追踪记录

## 实施步骤

1. 将密码长度提示并入标签标题行，避免独立帮助行改变网格高度。
2. 为运营表单字段建立统一的标签轨道、控件轨道、内边距和轻量玻璃背景。
3. 统一原生输入框、Element Plus 选择器和提交按钮高度。
4. 验证桌面与手机布局、横向溢出和浏览器控制台。

## 验收标准

- 创建用户表单五个输入控件顶部和高度一致。
- 创建 3D 展项八个字段卡在两行内保持统一高度。
- 提示文字和“可选”标记不再造成控件位移。
- 桌面 `1433x746` 与手机 `390x844` 无横向溢出。
- 类型检查、测试、生产构建和 Docker 前端重建通过。

## 风险

- 窄列中的辅助文字可能换行；通过右侧定位与不换行规则保持控件轨道稳定。
- 统一字段卡会增加少量表单高度；手机端改为单列，不压缩输入控件触控尺寸。

- `corepack pnpm typecheck`：通过。
- `corepack pnpm test`：10 个测试文件、38 项测试全部通过。
- `corepack pnpm build`：通过；仅保留既有 Three.js 大型 chunk 提示。
- Docker 前端镜像重建并强制替换成功，`/admin/operations` 返回 HTTP `200`。
- 桌面 `1433x746`：用户表单五个字段卡约 `90px` 高，所有输入框顶部一致且均为 `46px` 高；3D 展项八个字段卡约 `90px` 高，两行内完全一致。
- 手机 `390x844`：用户表单五个字段卡均约 `309x90px`，页面无横向溢出。
- 浏览器控制台无错误；`git diff --check` 通过。

# 首页、数字展厅与登录卡细节精修计划

## 目标

修复数字展项路由进入后沿用上一页滚动位置的问题，并精修首页 CTA、展厅渲染模式切换、视角缩略图和登录毛玻璃卡片，使交互更直观且延续河洛纸墨视觉。

## 关联需求

- F-05：3D 数字展项展示与交互
- F-08：账户登录与身份入口
- F-01/N-03：公开入口、响应式与交互易用性
- N-06：工程检查、验证和实施记录

## 影响范围

- Vue Router 页面滚动恢复
- 首页底部两个 CTA 的结构与样式
- 数字展项的实体/点云切换、场景标签和视角缩略图
- 登录页玻璃卡片、输入框和自动填充状态
- 对应响应式、无障碍和项目状态文档

## 验收标准

- 从任意已滚动页面进入数字展项时，页面定位到顶部，鼎在首屏完整可见。
- 实体建模和点云解构可以从底部 Dock 直接切换，选中、禁用和键盘焦点状态明确。
- 五个视角缩略图的鼎主体视觉尺度协调，正面不再明显大于其他视角。
- 场景标签不再显示无功能的下拉符号。
- 首页两个 CTA 的文字、图标和按钮比例统一，桌面与手机不发生布局跳动。
- 登录卡与首页路线卡使用一致的墨玉毛玻璃层级，浏览器自动填充不产生突兀底色。
- 类型检查、测试、生产构建和目标路由浏览器回归通过。

## 风险

- 全局路由回顶会改变前进导航的默认滚动行为；浏览器后退仍保留 `savedPosition`。
- 缩略图素材构图不同，采用视角级 CSS 校正而不改动正式资产。

# 前端细节优化实施计划

- 日期：2026-08-02
- 状态：已实施；工程、Docker、浏览器、Performance trace 与 Android 真机自动化完成，真人手感待补
- 关联需求：F-01 至 F-13、N-03、N-06
- 设计基线：根目录 `design.md` 中锁定的“河洛纸墨”系统

## 目标

在不改变后端 API、数据库、鉴权、路由、预约和订单状态机的前提下，完成前后台视觉一致性、交互状态、键盘与辅助功能、响应式和性能收口，并补充可复现的工程与浏览器验收证据。

## 影响范围

- `frontend/src/App.vue`、共享组件和前端样式：导航、焦点、状态、Sheet、媒体偏好和触控体验。
- 前台与后台 Vue 页面：页面语义、错误/空状态、图片加载、移动端和键盘流程。
- 前端测试、`PROJECT_STATUS.md` 和需求追踪表：记录验证结果与剩余风险。
- 不处理当前工作区内无关的后端、模型、Blender、截图和素材改动。

## 实施步骤

1. 统一语义令牌、控件状态、焦点、减少动态/透明度和高对比度规则。
2. 优化应用壳层、路由焦点、移动导航和共享交互组件。
3. 逐页完善公众端、3D、预约、商城、认证、个人中心和后台语义。
4. 扩展单元测试，运行类型检查、测试、构建、Docker 与浏览器回归。
5. 更新项目状态和需求追踪表，审查 diff 后等待用户确认提交。

## 验收标准

- `320x800`、`375x812`、`390x844`、`414x896`、`768x1024`、`1024x768`、`1440x900`、`1672x941` 无关键溢出、遮挡或文字截断。
- 核心控件具备默认、悬停、焦点、按压、禁用、加载、成功和失败状态。
- 键盘、ESC、Sheet 焦点回归、减少动态、减少透明度和高对比度不阻断核心流程。
- 普通路由不预加载 Three.js；本轮不新增大型依赖，构建体积不高于基线。
- `pnpm typecheck`、`pnpm test`、`pnpm build`、Docker 服务和三角色核心浏览器流程通过。

# 首页视觉还原实施计划

- 日期：2026-08-01
- 状态：进行中
- 关联需求：F-01、F-05、F-12、N-03、N-06
- 视觉依据：项目组确认的“宣纸底纹 + 深墨绿斜切展区 + 青铜器主视觉 + 文明时间轴”首页效果图。

## 目标

将首页从通用的双栏介绍页调整为沉浸式博物馆入口页：以河洛文明叙事为主线，引导年轻文化探索者浏览馆藏和数字展厅，同时不改变现有路由、登录、语言切换与响应式能力。

## 设计方案

- **色彩**：宣纸米白 `#efe4cd`、墨绿 `#10251e`、青铜金 `#a78b56`、朱砂 `#9d3f2c`、墨色 `#28271f`。
- **排版**：标题使用宋体优先的高对比衬线字；正文使用系统中文无衬线字；导航保持小字号和较大字距。
- **构图**：左侧为标题、导语和单一主要行动；右侧以倾斜裁切的深色展区承载项目组自创青铜鼎图片；底部为河洛文明阶段时间轴。
- **标志性元素**：一条由左下延伸至青铜器的“河流”SVG 线稿，将时间轴、河洛主题与主视觉连接起来。

## 影响范围

- `frontend/src/App.vue`：首页专用页头布局与移动端菜单开关。
- `frontend/src/views/HomeView.vue`：首页语义结构、双语文案和时间轴。
- `frontend/src/assets/main.css`：首页专用的视觉与响应式样式。
- `frontend/src/stores/locale.ts`、`frontend/src/test/HomeView.spec.ts`：同步首页双语静态文案及测试断言。

## 验收标准

1. 桌面端首页呈现“浅色宣纸左区 + 深色斜切右区 + 青铜鼎 + 底部时间轴”的视觉层次。
2. “探索河洛”入口可进入 `/explore`；现有导航、语言切换、登录入口均可用。
3. 窄屏下内容不横向溢出，主图与时间轴转为纵向可读布局。
4. 前端类型检查、单元测试、生产构建通过，并用本地浏览器检查首页。

## 风险

- 现有自创青铜鼎是横向图片，无法与参考图中的方尊角度完全一致；保留资产本体，仅通过裁切、色调和构图接近目标。
- 纸张肌理和河流线条用 CSS/SVG 实现，不新增来源不明的纹理图片或字体。

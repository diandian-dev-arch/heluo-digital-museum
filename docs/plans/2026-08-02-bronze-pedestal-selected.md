# 青铜鼎展厅黑石金线底座实现计划

## 目标

将数字展厅当前浅色发光底座改为用户确认的深灰黑石圆形展台：实体深色材质、分层台面、外圈厚重边缘和一条细窄暖金装饰线。底座不再使用大面积自发光，避免遮挡青铜鼎纹饰和造成过曝。

## 实施范围

- 只调整 `ThreeExhibitViewer.vue` 中展台几何体和材质。
- 保留青铜鼎模型、相机、灯光平衡、点云颜色、视角切换、旋转/缩放/复位和资源释放逻辑。
- 使用 Three.js 实体几何重建圆形黑石台面和暖金细线，不使用整图背景。

## 验收标准

- 底座呈深灰黑石质感，具有明显厚度和分层边缘。
- 暖金线细窄、连续、低调，不形成发光白斑或大面积光晕。
- 青铜鼎纹饰、古铜反射和三足结构仍然清晰可见。
- 类型检查、单元测试、生产构建和 Docker 前端服务检查通过。

## 验证结果

- 已将展台改为深灰黑石材质的分层圆形底座，保留实体厚度与外圈边缘。
- 已新增一条非自发光的暖金色细窄装饰环，避免形成白色过曝光晕。
- 已保留青铜鼎模型、当前灯光平衡、点云配色、相机视角、旋转/缩放/复位和资源释放逻辑。
- `pnpm typecheck`、`pnpm test -- --run`、`pnpm build` 通过；Docker 前端重建、容器状态、`http://localhost:8088/` HTTP 200 检查通过。
- 未执行真实登录态下的数字展厅截图复核；需要在浏览器保持有效会话后补充视觉验收。

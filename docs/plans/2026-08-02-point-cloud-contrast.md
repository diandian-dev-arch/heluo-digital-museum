# 数字展厅点云对比度修复

- 状态：二次提亮与 Android 生产真机复验完成；用户人工亮度与触控观感确认通过
- 关联需求：F-05、N-03、N-06

## 目标

修复深墨青铜厅在 Android 移动画质档中点云过暗、轮廓与背景融合的问题。只调整 Three.js 点云 shader 的显示调色，不改变模型、API、交互方法、粒子预算和点云质量策略。

## 实施

- 桌面继续使用现有深墨玉与少量青铜金，不改变既有视觉。
- 首轮移动档使用独立 shader uniform，将轮廓可见像素占比从 `10.3%` 提升到 `40.8%`。
- 根据真机观感反馈执行二次提亮：青玉基色由 `[.075, .24, .15]` 提升为 `[.12, .48, .30]`，古铜由 `[.52, .25, .065]` 提升为 `[.78, .50, .16]`，古铜混合范围收敛到 `12%-34%`，粒子不透明度改为 `1`。这样提升整体明度，同时避免整件器物继续偏成低对比度暗橄榄色。
- 保留点云粒子大小、聚合动画、实体/点云切换和性能降级逻辑。
- palette 单元测试固定移动青玉亮度下限 `.38`、相对桌面至少 `6x`、古铜亮度下限 `.50`、古铜占比上限和桌面配置不变。

## 验收标准

- 点云轮廓在深墨背景上清晰可辨，保持博物馆墨绿/青铜品牌语气。
- 实体模式、点云模式、旋转缩放和页面离开资源释放逻辑不受影响。

# 数字展厅参考图还原实施计划

## 目标

将三足青铜鼎数字展厅真实 Vue 页面还原到用户确认的月白青玉参考图：暖白展厅主舞台、浅色全站导航、深绿半透明信息栏、左侧紧凑工具栏和底部悬浮导览 Dock。

## 关联需求

- F-05：游客可进入 3D 展厅查看已发布展项
- N-03：前端响应式与可访问性
- N-06：前端可维护性

## 影响范围

- `frontend/src/views/ExhibitDetailView.vue`
- `frontend/src/assets/main.css`
- `frontend/src/components/ThreeExhibitViewer.vue`
- 不改变 API、Three.js 模型、点云状态机、权限或订单业务。

## 验收标准

- 桌面端还原参考图的导航、背景、模型位置、右栏、工具栏、悬浮 Dock 和视角缩略图。
- 右栏标题、来源、材质、说明、关联文物与预约操作仍可用；点云从导览第 5 步进入。
- 390px 移动端保持信息 Sheet、底部导航、双指 3D 交互和无横向溢出。
- `pnpm typecheck`、相关单测、`pnpm build` 通过，并完成 1440px/390px 浏览器截图与控制台检查。

## 风险

- 参考图背景中的树影和铭文墙优先复用已登记的 `museum-corridor-hero.webp`；该素材本身包含远景展品，由前景真实 Three.js 模型在正常构图中遮挡，不把概念图直接作为页面背景。
- 透明面板和悬浮 Dock 在低对比度显示器上需结合 `prefers-contrast` 做降级。

## 实施与验证结果

- 已完成浅色导航、月白展厅背景、暖白工具栏、深墨绿信息面板、悬浮导览 Dock 和五个视角缩略图的参考图还原；“返回展厅”已收进右侧信息面板标题行。
- 已按首页参观路线卡片统一毛玻璃材质：右侧信息面板使用深墨绿半透明底、细白高光边、`16px` 模糊与克制内阴影，并缩小面板宽度和标题尺度；暖白 Dock 使用同级模糊、饱和度和高光边，保持深浅材质层级。

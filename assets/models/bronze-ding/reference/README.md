# 青铜鼎 v5 设计参考

本目录的两张 PNG 由项目组于 2026-08-01 使用 Codex 图像生成功能自主生成，作为原创概念礼器 v5 的器型、纹样和材质方向参考。

| 文件 | 用途 |
|---|---|
| `heluo-bronze-ding-v5-main-design-reference.png` | 主视觉：确定深褐黑铸造青铜、双耳、三足及连续纹样的质感方向。 |
| `heluo-bronze-ding-v5-turnaround-reference.png` | 正、侧、背、俯视：确定器腹、口沿、耳部与三足的结构比例。 |

它们不是实际文物摄影、扫描数据或运行时网页背景；网站交互展项使用项目组在 Blender 自主创作并导出的 `heluo-bronze-ding-v5.glb`。

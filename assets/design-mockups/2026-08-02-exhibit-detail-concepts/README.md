# 三足青铜鼎数字展项页：三套视觉优化方案

> 本目录为概念设计参考，不是已实现页面。效果图由 ImageGen 基于当前页面截图生成；后续应使用真实 Vue DOM、CSS 设计令牌和 Three.js 重建，禁止直接把整张效果图当页面背景。

## 共通保留项

- 河洛数字博物馆品牌和顶部主导航。
- 三足青铜鼎作为唯一视觉主体。
- 旋转、放大、缩小、重置等基础 3D 操作。
- `三足青铜鼎 · 1962.281`、`Cleveland Museum of Art · 1962.281` 等已有来源信息。
- 实体/点云切换、六段展览导览和五个预设视角。
- 深墨绿、青铜、月白构成的东方编辑策展基调。

## 方案 A：沉浸文物剧场

效果图：`heluo_exhibit_concept_a_theater.png`

- **核心策略**：让器物占据更大的视觉面积，以低干扰舞台、暖色主光和克制轮廓光突出纹饰与材质。
- **布局变化**：右侧卡片改为无外框信息列；底部保留完整导览和视角胶片；控制条进一步收窄。
- **优势**：视觉冲击最强，进入页面即可聚焦文物，和当前深色展厅的改造成本最低。
- **风险**：页面整体较暗；需为正文、焦点态、模型加载失败和低性能降级保持足够对比度。
- **适用场景**：作为正式线上数字展厅和传播截图，优先面向普通游客。

## 方案 B：编辑式学术展陈

效果图：`heluo_exhibit_concept_b_editorial.png`

- **核心策略**：采用“深色 3D 舞台 + 月白目录页”对开结构，让模型体验和策展阅读同等重要。
- **布局变化**：右侧用博物馆目录式排版组织标题、来源、材质和说明；底部视角像档案接触印样；朱砂仅用于微小标注。
- **优势**：信息可读性最好，与 `design.md` 的“河洛纸墨”编辑策展系统最一致，也最容易延展到馆藏详情页。
- **风险**：明暗分屏需要精确处理 1280px 和平板断点；浅色区域不能削弱 3D 主体。
- **适用场景**：强调知识传播、课程展示和品牌统一时优先。

## 方案 C：高效数字研究台

效果图：`heluo_exhibit_concept_c_research.png`

- **核心策略**：将页面组织成模式栏、3D 检视画布、分析侧栏三个稳定区域，突出点云、纹样和材质层级。
- **布局变化**：左侧增加探索/测量/标注/对比等模式入口，中央提供局部放大观察，右侧用页签和图层控制组织信息，预设视角固定在画布下方。
- **优势**：信息密度与专业感最高，适合展示数字化能力，也为未来纹样讲解或教学模式留出空间。
- **风险**：其中测量、标注、对比、切面和图层开关属于概念功能，当前项目没有对应业务实现；若选择此方案，应先决定是否只保留视觉组织，不扩充第一版范围。
- **适用场景**：课程答辩、数字保护专题、面向研究型访客的高级模式。

## 推荐选择

- **主方案推荐 B**：最符合现有“河洛纸墨”设计系统，同时明显改善当前右侧信息卡偏重、底部信息割裂的问题。
- **建议吸收 A**：把 A 的器物尺度、灯光和无外框信息层级合入 B，可同时兼顾沉浸感与阅读性。
- **C 作为后续模式**：第一版先不增加测量、标注等新功能；可保留其紧凑页签和视角胶片组织方式。

## 后续落地顺序

1. 先确定 A、B、C 或混合方向，并冻结桌面信息架构。
2. 用真实文本重建标题、来源、材质、说明和按钮，避免沿用效果图中的生成文字。
3. 调整 Three.js 画布与模型相机，让器物在信息栏外的可用区域中真正居中。
4. 重做桌面底部导览与预设视角，再设计 768px 和 390px 的信息 Sheet。
5. 最后补齐 loading、error、fallback、focus、reduced-motion 和低性能模式并执行真实浏览器验收。

# 数字展厅 UI 优化方案（第二轮）

> 本轮只研究数字展厅的 UI 信息架构、控件布局和交互主次。青铜鼎、展台、灯光、深色场景和现有业务功能保持不变。

## 为什么重做

上一轮把差异主要做成了展厅氛围和视觉风格，偏离了“优化现有数字展厅 UI”的目标。本轮明确排除美术场景重做和新功能扩张，重点解决：

1. 右侧信息卡过重，和青铜鼎争夺注意力。
2. 左侧工具纵向占高，缺少状态和主次。
3. 实体/点云、画质、来源与说明分散。
4. 底部导览、视角和来源分成三块，信息重复。
5. 当前步骤和当前视角的选中反馈偏弱。
6. 同屏边框和卡片过多，空间显得拥挤。

## 方案 A：均衡侧栏式

效果图：`heluo_ui_v2_a_balanced_sidebar.png`

- 右侧采用贴边信息栏，不再使用悬浮大卡片。
- 实体/点云与质量状态集中在信息栏顶部。
- 六段导览与五个视角合并为一个底部控制坞。
- 删除单独的模型来源卡，来源只在右侧出现一次。
- 保留左侧纵向工具，学习成本最低。

适合小步修改、尽量保持当前页面结构；不足是右侧仍长期占据固定宽度。

## 方案 B：沉浸浮动式

效果图：`heluo_ui_v2_b_immersive_controls.png`

- 四个 3D 操作合并为画布左下的横向工具组。
- 右侧信息面板可以收起，画布占比最大。
- 六段导览作为细进度条，五个视角集中到中央胶片带。
- 操作控件更靠近模型，适合快速观察。

适合优先强化 3D 观看体验。效果图仍残留底部模型来源区，实际实现时应删除。

## 方案 C：导览任务式（推荐）

效果图：`heluo_ui_v2_c_guided_journey.png`

- 左侧只负责六段展览导览，当前步骤带简短说明。
- 画布左下只负责旋转、缩放和重置。
- 右侧只负责当前展项信息、实体/点云、状态和两项业务入口。
- 底部只负责五个预设视角，并明确显示 `01 / 05`。
- 每个区域只有一个职责，没有重复来源或重复导览。

适合普通游客按步骤理解器物，同时保留自由 3D 操作。中文、尺寸和组件结构由 HTML/CSS 确定性渲染，可直接作为实现基准。

## 推荐落地方案

采用 **C 的信息架构 + B 的可收起右侧面板**：桌面默认显示左侧六步导览、中央 3D、右侧信息栏和底部视角；用户收起信息栏后扩展画布；四个 3D 操作使用左下横向工具组；来源只显示在信息栏。

## 组件级改造映射

### `ExhibitDetailView.vue`

- 将 `tour-route` 从底部移为左侧 `exhibit-guide-rail`，继续复用现有六项数据。
- 将 `viewer-tools` 改为画布左下横向工具组，保留原点击处理函数。
- 将 `exhibit-panel` 改为贴边信息栏，并增加前端本地折叠状态。
- 将 `mode-switch` 与 `render-quality` 保持相邻。
- 删除 `exhibit-location` 独立区块，来源只使用 `exhibitFacts`。
- 将 `view-switcher` 保留为唯一底部区域，强化当前视角和 `01 / 05` 反馈。

### `ThreeExhibitViewer.vue`

- 无需修改模型、点云算法、相机预设或资源释放逻辑。
- 右侧栏折叠时依靠现有 `ResizeObserver` 更新画布尺寸。

### CSS

- 桌面建议采用 `286px / minmax(0, 1fr) / 340–372px` 三列。
- 控件最小点击区域保持 `44px`，圆角统一为 `4–6px`。
- 只为区域边界使用 1px 分隔线，删除重复描边和装饰性投影。
- 主选中态使用青铜金；质量状态使用青绿。
- 768px 以下继续使用现有 Bottom Sheet，不照搬三列布局。

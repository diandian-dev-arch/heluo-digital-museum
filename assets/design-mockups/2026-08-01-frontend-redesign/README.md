## 使用边界

- 这些图片是视觉方向效果图，不是可直接上线的页面截图或前端切图。
- 选定方向后，应在 Vue/CSS 中重建排版、组件和响应式规则，并保留真实业务状态。
- 图中文字以设计构图参考为主，编码时以项目现有中英文文案和接口数据为准。
